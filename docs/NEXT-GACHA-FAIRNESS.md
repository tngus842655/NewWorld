## 1. 배경 — 무엇을 묻다가 나온 건가

사용자 발제: *"상점 뽑기가 해금 지역 몬스터만 주는 건 같은 돈을 쓰는 유저 사이에 형평성이
안 맞는 것 아닌가?"*

분석 결과 **전제는 틀렸고, 형평성 문제는 반대 방향으로 존재**한다.

**전제가 틀린 이유** — [src/core/shop.ts:151](../src/core/shop.ts) 뽑기는 *등급을 먼저 굴리고*
그 다음 해금 풀에서 종을 고른다. 등급표(`balance.shop.monsterGacha`)는 해금 지역 수와 무관하게
고정이므로, 150💎당 전설 1%는 1지역 유저나 12지역 유저나 동일하다. **재화 대비 등급 품질은 같다.**

**진짜 문제 — 후반부 풀 희석** — 지역 12개 × 전설 2종 = 전설 풀이 최대 24종까지 불어나는데,
"지금 쓸 수 있는 전설"은 여전히 최신 지역 2종뿐이다.

| 해금 | 뽑기 1회 E[CP] | 최신 지역 출신 확률 | E[CP] ÷ 최신 지역 권장CP(deep) |
|---|---|---|---|
| 1 물안개 해안 | 37 | 100% | **0.081** |
| 6 고목의 우듬지 | 98 | 16.2% | 0.044 |
| 12 분화구 심장부 | 300 | 8.1% | **0.023** |

고급 뽑기 10연(3,600💎) 기준 "지금 쓸 전설" 최소 1장 확률: 1지역 **26.3%** vs 12지역 **2.47%**
(**10.6배** 차이). 돈을 쓰는 쪽은 후자다.

이건 이미 [GDD.md:692](GDD.md) 에 기록돼 있다 — *"뽑기는 풀이 '해금한 모든 지역'이라 원하는 지역을
노릴 수 없고 중복이 많다"*, 바로 아래 줄이 *"과금 동기가 없다"*. 같은 원인이다.

**그럼에도 풀 전면 개방은 기각** — `crater-empress` CP 5,500 vs 물안개 해안 심층 권장 CP 460
(12배). 1지역에서 한 장 터지면 1~3티어가 통째로 증발한다. **해금 지역 제한 자체는 유지한다.**

추가로 발견한 구조적 문제: **하위 티어 전설 카드는 출구가 없다.**

- 쓸 수 없다 — 물안개 전설 CP 340 vs 분화구 전설 5,500 (16배)
- 합성 못 한다 — 초월 합성이 최종 티어 서식 카드만 재료로 받음
- 분해 못 한다 — 2026-08-25 기능 제거

→ **작업 2의 동기**가 여기서 나왔다.

## 2. 확정 사항 (2026-08-31 사용자)

### 작업 1 — 상점에 "해금 지역 한정" 고지 추가 ✅확정

지금 해당 문구는 확률 정보 시트([overlays.ts:473](../src/ui/overlays.ts))에만 있고
**상점 화면에는 없다.** 유저가 형평성을 의심하는 지점이 정확히 거기다.
→ 뽑기 상품 카드/구매 시트에 한 줄 노출.

### 작업 2 — 초월 합성 재료 완화 + 관문을 **분화구 심장부** 해금으로 ✅확정

- **재료 제한 철폐**: 하위 지역 전설 여분 카드도 초월 재료로 사용 가능
- **관문**: `crater-heart`(분화구 심장부) 해금 이후에만 초월 도전 가능

> ⚠️ **사용자 최초 제안은 "화산(`ashen-volcano`) 해금 이후"였으나, §4.2의 폴백 구멍 때문에
> 논의 끝에 분화구로 변경 확정.** 시뮬 중앙값 기준 화산 D26~28 / 분화구 D29~33이라
> 체감 차이는 3~5일이고, 대신 진행 파괴 경로가 완전히 닫힌다.

이 변경의 의미: 지금 **몬스터 초월과 유물 초월이 서로 다른 방식으로 잠겨 있다.**

| | 개편 전(2026-08-25~09-01) 게이트 방식 — 착수 당시의 "현행" |
|---|---|
| 몬스터 초월 | 재료가 **최종 티어 서식 전설**이어야 함 ([economy.ts:123-133](../src/core/economy.ts)) — 지역 해금 검사 없음 |
| 유물 초월 | 재료 제한 없음 + **잿빛 화산 해금** 필요 ([economy.ts:229-235](../src/core/economy.ts)) |

작업 2는 몬스터를 유물 방식으로 통일하는 것이다. 유물 쪽 주석이 이미
*"몬스터의 '최종 티어 재료' 규칙에 대응하는 등가로 최종 티어 진입을 요구한다"* 라고
두 규칙을 등가로 의도했다고 적고 있으므로 **원래 설계 의도와 어긋나지 않는다.**

단 게이트 지역은 갈린다 — **몬스터=분화구, 유물=화산.** 의도된 비대칭이다
(유물은 서식 지역 개념이 없어 폴백 구멍이 없다). 안내 문구에서 헷갈리지 않게 쓸 것.

## 3. 근거 수치 — 이 변경이 얼마나 크게 여는가

봇 시뮬 계측 (보통 접속 = 하루 4회, `spendPolicy: 'codex'`, `fuseSpares: true`,
`codexRotate: true`, `alwaysDeep: true`, D120, 시드 5개 중앙값):

| 케이스 | 화산D | 분화구D | 전설 보유종 | 전설 여분 | 그중 최종티어 |
|---|---|---|---|---|---|
| 무과금 · 여분합성X | 28 | 33 | 6종 | 5장 | **0장** |
| 무과금 · 여분합성O | 27 | 30 | 19종 | 52장 | 9장 |
| 월5만 · 여분합성O | 26 | 29 | 20종 | 41장 | 11장 |
| 월20만 · 여분합성O | 20 | 25 | 21종 | 54장 | 9장 |

**초월 성공률 3%, 재료 2장, 실패 시 1장 반환 → 실소모 1장/시도.** 여분 N장 ≈ N−1회 시도.

| | 재료 가능 여분 | 시도 횟수 | P(초월 ≥1종) |
|---|---|---|---|
| **현행** (최종티어만) | 9장 | 8회 | **21.6%** |
| **완화 후** (전 지역) | 52장 | 51회 | **78.8%** (기대 1.53종) |
| 여분합성 안 하는 유저 | 5장(최종티어 0장) | 현행 0회 → 완화 4회 | 0% → **11.5%** |

**시도 횟수 6.4배, 도달률 21.6% → 78.8%.** 이건 "죽은 카드를 살린다"보다
**엔드콘텐츠 관문을 6배 넓힌다**에 가깝다. 2026-08-25에 사용자가 직접 "엔드콘텐츠 관문"으로
좁힌 규칙이므로, 착수 시 이 폭을 다시 한 번 확인할 것.

> 과금 구간이 큰 영향을 못 준다는 점에 주의 — **전설의 주 획득 경로는 과금이 아니라
> 영웅→전설 여분 합성 사다리**다. 여분 합성을 안 돌리는 유저는 현행 규칙에선 영원히
> 초월에 도달하지 못한다(최종티어 여분 0장). **완화안의 진짜 수혜자가 이쪽이다.**

**재현 방법**: ~~임시 스크립트 재작성~~ → **`npx tsx scripts/transcend-sim.ts --days 120 --seeds 5 --tiers f2p,mid,high`**
(2026-09-02 영구화 — `bot.ts`에 `fuseTranscend` 옵션·`DayRow` 전설 여분 필드·`SimResult.transcend`가 상주).
위 표의 "여분 N장 ≈ N−1회" 정적 산술과 달리 스크립트는 봇이 여분을 생기는 즉시 소모하는 동적 계측이라 값이 다르다 — §9.3.
D150은 2분 타임아웃에 걸리므로 **D120 이하로** 돌릴 것.

### 4.1 코어 — 재료 규칙 교체

[src/core/economy.ts:123-133](../src/core/economy.ts) 현행:

```ts
// 초월 도전은 최종 티어 서식 카드만 재료로 쓸 수 있다 (2026-08-25 사용자) — 엔드콘텐츠 관문
if (isTranscendStep(nextRarity)) {
  const entry = finalTierEntry(content);
  for (const material of input.materials) {
    const monster = content.monsters.get(material.monsterId)!;
    if (!isFinalTierNative(content, monster.id)) {
      throw new GameError('fusion-region',
        `${RARITY_LABEL[nextRarity]} 합성은 ${entry.name} 권역 서식 카드만 재료가 됩니다 (${monster.name}은 다른 지역)`);
    }
  }
}
```

→ 유물 쪽(229-235행)과 같은 형태로 교체:

```ts
if (isTranscendStep(nextRarity)) {
  const gate = transcendGateRegion(content);
  if (!isRegionUnlocked(content, save, gate.id)) {
    throw new GameError('fusion-region',
      `${RARITY_LABEL[nextRarity]} 합성은 ${gate.name}을(를) 해금해야 도전할 수 있습니다`);
  }

```

### 4.2 ⚠️ 반드시 같이 고칠 것 — 결과 풀 폴백 구멍

[src/core/economy.ts:153-157](../src/core/economy.ts):

```ts
// 결과 풀: 해금 지역의 다음 등급 전 종 (전 지역 미해금 케이스 방어로 전체 폴백)
let pool = content.monsterList.filter(
  (m) => m.rarity === nextRarity && isRegionUnlocked(content, next, m.habitat),
);
if (pool.length === 0) pool = content.monsterList.filter((m) => m.rarity === nextRarity);
```

**초월 3종(`emberwing-sovereign`·`obsidian-wyrm`·`dawnscale-drake`)은 전부 `crater-heart` 서식이다.**
분화구 미해금 상태에서 초월에 성공하면 → 풀이 비어서 → **폴백이 분화구 초월 몬스터를 그냥 준다.**

- 초월 CP **8,250~8,324** vs 잿빛 화산 심층 권장 CP **4,500**(1.8배), 용암 협곡 6,300
- 화산 게이트를 택했다면 D26~33 사이 **3~5일짜리 진행 파괴 창**이 열린다
- 이 구멍은 **지금도 이론상 존재**한다(화산 전설 2종 여분 2장이면 도달). 다만 화산 해금 시점의
  최종티어 여분이 중앙값 0장이라 실제로 안 터진다. **재료 완화가 이걸 상시 경로로 승격시킨다.**

**분화구 게이트를 택했으므로 이 경로는 원천 차단된다.** 그래도 방어를 이중으로 둘 것:
초월 단계에서는 폴백을 타지 말고 `GameError`를 던진다(도달하면 그 자체가 게이트 버그 신호).

### 4.3 새 헬퍼 — `transcendGateRegion`

`finalTierEntry`는 최종 **티어의 진입 지역**(=잿빛 화산)이라 이 용도에 맞지 않는다.
초월 종의 서식지에서 데이터로 유도할 것 (지역이 늘어나도 자동으로 따라오게 —
`finalTier`의 기존 설계 철학과 동일):

```ts
/** 초월 관문 지역 — 초월 종 서식지 중 해금이 가장 늦은 곳. 결과 풀이 비지 않는 시점이 곧 관문 */
export function transcendGateRegion(content: Content) {
  const homes = new Set(content.transcendentList.map((m) => m.habitat));
  return content.regionList.filter((r) => homes.has(r.id)).sort((a, b) => b.order - a.order)[0]!;
}
```

`content.transcendentList`는 [src/content/index.ts:110](../src/content/index.ts)에 이미 있다.
*(전제: 지역 해금이 순차적이라 가장 뒤 지역이 해금되면 앞 지역도 전부 해금돼 있다. 현재 콘텐츠는 참.)*

`isFinalTierNative`는 몬스터 쪽 사용처가 사라진다 — 유물/표시 전용으로 남기거나 정리.

## 5. 남는 한계 — 기대치 조정

**뽑기 사표 문제는 절반만 풀린다.** 재료는 **여분(`count - 1`)** 만 되므로, 뽑기로 처음 얻은
하위 지역 전설 1장은 여전히 묶인다(도감 등록 가치만). 2장째부터 가치가 생기는 구조다.
"§1에서 지적한 사표 문제를 해소한다"고 과대평가하지 말 것.

### 9.2 문서와 다르게 한 것

- **core 에러 문구는 조사 없이** — "…은 {지역} 해금 후에 도전할 수 있습니다". `josa()`는 `ui/kit.ts`에 있고 core는 ui를
  import하지 않는다(기존 관례인 "이(가)" 병기보다 문장을 바꾸는 쪽을 택했다). UI 문구는 `josa()` 사용.
- **확률 시트에 유물 관문 줄 추가** — §2 "안내 문구에서 헷갈리지 않게"의 이행. 몬스터=분화구 심장부, 유물=화산 권역을 나란히.
- **구매 확인창에도 한 줄** — §4.5 "상품 카드/구매 시트"의 '구매 시트' 해석. 구간 머리 한 줄 + 확인창 한 줄.
- `materialsAll`은 상품 desc가 이미 "해금 지역 재료를 각 n개씩"이라 추가 표기 없음.

### 9.3 계측 (D120 · 시드 5 · "보통" 완성 지향 · 다이아는 고급 뽑기)

`npx tsx scripts/transcend-sim.ts --days 120 --seeds 5 --tiers f2p,mid,high`. 같은 시드로 구 규칙(봇이 최종 티어 서식
여분만 재료로 고름)과 현행을 비교. 관문(분화구 해금)은 둘 다 같다.

| 구간 | 분화구D | 규칙 | 시도(평균) | 성공(평균) | 초월 ≥1종 도달 | 첫 초월 일차 |
|---|---|---|---|---|---|---|
| 무과금 | D31 | 구 | 9.0 | 0.20 | 1/5 | D82 |
| 무과금 | D31 | **현행** | **34.2** | **0.80** | **3/5** | D62 · D68 · D81 |
| 월 5만 | D29 | 구 | 6.4 | 0.20 | 1/5 | D67 |
| 월 5만 | D29 | **현행** | **43.6** | **1.40** | **4/5** | D57 · D62 · D78 · D95 |
| 월 20만 | D21 | 구 | 10.2 | 0.20 | 1/5 | D48 |
| 월 20만 | D21 | **현행** | **50.4** | **1.40** | **4/5** | D42 · D79 · D88 · D103 |

- §3의 해석적 추산(21.6% → 78.8%)보다 폭은 작다 — 봇은 여분이 생기는 즉시 소모하므로 "D120에 52장 쌓아 51회"가 아니라
  관문 이후 흘러드는 여분을 그때그때 쓴다(시도 34~50회). 방향과 자릿수는 같다: **도달 시드 1/5 → 3~4/5, 시도 3.8~6.8배**.
- 과금 구간 차이가 작다 — 전설의 주 경로가 영웅→전설 여분 합성 사다리라는 §3의 관찰과 일치.
- 구 규칙 행은 **재료 규칙만** 에뮬레이션 — 관문(분화구)은 현행 코어를 타므로 구 규칙(지역 관문 없음)보다 엄격하다.
  화산~분화구 해금 사이(D21~31 구간)의 시도분은 빠져 있으나, 그 창의 최종 티어 여분 중앙값이 0장(§3 표)이라 과소평가 폭은 작다.
- **해금 곡선 변화 0** — `spend-sim.ts --days 35 --seeds 5`를 HEAD 워크트리와 작업 트리에서 각각 돌려 출력 바이트 동일.
  봇은 전설 합성을 기본으로 켜지 않고, 관문이 마지막 지역이라 초월이 해금을 앞당길 경로가 없다. GDD §9.1-2 재측정 의무 이행.
