# NewWorld — 게임 설계서 (GDD)

> 몬스터 포획 원정 RPG · 앱인토스 미니앱 우선 · v1 기준
> 상태: **초안 (M0 리뷰 대상)** · 마지막 수정: 2026-08-22

---

## 1. 한 줄 정의

**미지의 신대륙 "뉴 월드"를 탐험하며 야생 몬스터를 포획해 나만의 원정대를 꾸리는 방치형 수집 RPG.**

- 장르: 방치형(파견) × 수집(도감) × 편성 퍼즐(시너지)
- 플랫폼: 앱인토스 웹 미니앱(세로·원핸드) → 이후 Google Play(Capacitor)
- 세션 패턴: 하루 3~6회, 회당 1~3분
- 아트: IconScout 3D 아이콘 (정적 오브젝트) — **전투 애니메이션이 필요 없는 설계**가 전제

### 세계관 톤

대항해시대 끝자락, 지도 밖에서 발견된 신대륙 **"뉴 월드"**. 플레이어는 탐험단의 단장이 되어
신대륙의 야생 몬스터를 포획하고 길들여, 더 깊은 미답지로 원정을 보낸다.
톤은 라이트 판타지 + 아기자기(3D 아이콘의 귀여운 렌더 톤과 일치). 텍스트는 전부 한글.

> 대안으로 검토했던 SF 외계행성 개척 테마는 몬스터 에셋 풀(판타지·할로윈 계열이 압도적)과
> 충돌해서 기각. M0 리뷰에서 뒤집을 수 있음.

## 2. 디자인 필러 (모든 결정의 기준)

1. **전투를 보여주지 않는다.** 재미의 본체는 수집·편성·성장이다. 전투는 "원정 일지"로 요약되고,
   조우 순간만 3초 컷(아이콘 흔들림 + 데미지 숫자 + 포획 이펙트)으로 연출한다.
2. **편성 화면이 메인 게임이다.** 속성 상성 × 종족 시너지 × 지역 특성의 조합 퍼즐.
   "어느 지역에 누구를 보낼까"가 매 파견마다 유의미한 선택이어야 한다.
3. **도감이 엔드 콘텐츠다.** 목격→포획→각성 3단계 기록. 도감 진척이 곧 파워(마일스톤 영구 버프)와
   콘텐츠 해금(지역·슬롯)으로 되먹임된다.
4. **토스라서 되는 것을 쓴다.** 푸시가 게임 메커니즘이다(귀환 알림, 갈림길 이벤트, 전설의 기척).
   방치형의 고질병인 재방문 루프를 플랫폼 인프라로 해결한다.
5. **모든 판정은 결정론이다.** 파견 시 시드가 확정되고 이후 모든 조우·포획·보상은 시드에서
   유도된다. 같은 입력 = 같은 일지. (서버 재검증 가능 → 랭킹 도입 시 치트 대응 경로)

## 3. 코어 루프

```
[편성] 몬스터 3~5마리 선택 (속성·시너지 퍼즐)
   ↓
[파견] 지역 × 길이(정찰 15분 / 원정 2시간 / 심층 8시간) 선택
   ↓
[방치] 실시간 경과 — 중간에 갈림길 이벤트 푸시(선택 응답)
   ↓
[귀환] 푸시 알림 → 원정 일지 열람 (조우 타임라인 리플레이)
   ↓
[획득] 포획 몬스터 도감 등록 · 전리품(골드/재료) · 목격 기록
   ↓
[성장] 레벨업 · 성급 각성 · 미끼 제작 · 도감 마일스톤
   ↓  (더 강해진 원정대로)
[해금] 더 깊은 지역 · 원정대 슬롯 · 동시 파견 팀 → 다시 [편성]
```

- **미드 루프**: 지역 도감 완성(지역당 12종), 종족 컬렉션, 시너지 조합 실험
- **롱 루프**: 전설 4종 포획(심층 한정), 전 도감 완성, (v1.5+) 별빛 폐허·랭킹

## 4. 몬스터 시스템

### 4.1 개체 구성

| 항목 | 내용 |
|---|---|
| 속성 | 화염 / 자연 / 냉기 / 빛 / 어둠 — 5속성 |
| 종족 | 야수 / 정령 / 언데드 / 수생 / 비행 / 기계 — 6종족 (시너지 축) |
| 등급 | 커먼 / 레어 / 에픽 / 전설 (도감 희귀도 = 포획 난도) |
| 스탯 | HP, ATK 두 개만. 전투력 CP = ATK × 2 + HP ÷ 2 |
| 성장 | 레벨 1~30 (골드), 성급 ★1~★5 (정수) |

스탯을 2개로 최소화한 이유: 전투를 보여주지 않으므로 스탯의 역할은 "파견 퍼즐의 숫자"다.
깊이는 스탯 개수가 아니라 상성·시너지 조합에서 나온다.

### 4.2 속성 상성 (배수)

```
화염 → 자연 → 냉기 → 화염   (삼각 순환, 유리 ×1.3 / 불리 ×0.77)
빛 ↔ 어둠                    (상호 유리 ×1.3)
그 외 조합                    ×1.0
```

지역마다 우세 속성이 있어(§6) 파티의 유효 전투력에 지역 상성 보정이 곱해진다.

### 4.3 종족 시너지 (편성 2 / 3마리 발동)

| 종족 | 2마리 | 3마리 |
|---|---|---|
| 야수 | 파티 ATK +10% | 파티 ATK +25% |
| 정령 | 조우 후 HP 5% 회복 | 조우 후 HP 12% 회복 |
| 언데드 | 전멸 피해 20% 경감 | 원정당 1회, 전멸 시 HP 30%로 부활 |
| 수생 | 늪·해안 지역 CP +15% | +30% 및 익사 함정 무효 |
| 비행 | 함정 이벤트 50% 회피 | 100% 회피 + 이동 조우 수 +1 |
| 기계 | 받는 피해 -8% | -20%, 단 정령 회복 효과 절반 |

- 수치는 전부 콘텐츠 JSON에 있으며 밸런스 시트(M3)에서 조정한다.
- 5칸 편성에서 "3+2" 이중 시너지가 이상적 조합 → 슬롯 확장의 가치를 만든다.

### 4.4 성장 곡선 (초안)

- 레벨 스탯: `stat(Lv) = base × (1 + 0.08 × (Lv - 1))` → Lv30 = base × 3.32
- 레벨업 골드: `cost(Lv) = 40 × Lv^1.6` (Lv1→30 누적 ≈ 5.2만 골드)
- 성급: ★당 스탯 ×1.25 (★5 = ×2.44). 필요 정수: 10 / 25 / 60 / 150 (★2~★5)
- 중복 포획 = 해당 종 **정수 자동 전환** (커먼 3 / 레어 8 / 에픽 20 / 전설 50)

## 5. 원정 시스템

### 5.1 파견 길이 3단

| 구분 | 시간 | 조우 수 | 특징 |
|---|---|---|---|
| 정찰 | 15분 | 3 | 튜토리얼·짬 플레이. 갈림길 없음 |
| 원정 | 2시간 | 8 | 표준. 갈림길 1회. 시간당 효율 ×1.2 |
| 심층 탐사 | 8시간 | 20 | 취침 전 파견. 갈림길 2회, 희귀 출현률 ×2, **전설은 심층에서만** |

- 동시 파견 팀 수: 시작 1팀 → 2팀(늪 해금 시) → 3팀(도감 40종)
- 파견 중인 몬스터는 다른 팀에 편성 불가(방치형 확장 축: 로스터가 넓어야 여러 팀)

### 5.2 조우 시퀀스 생성 (결정론)

파견 확정 시 `seed`가 정해지고, 시드에서 조우 시퀀스가 유도된다:

```
각 슬롯 roll → 몬스터 조우 72% / 보물 12% / 함정 10% / 채집 6%
몬스터 조우: 지역 출현 테이블(가중치)에서 종 선정 → 난이도 E 산출
```

### 5.3 조우 판정 모델

파티 유효 전투력:

```
P = Σ_unit ( CP × elemMult(unit.elem, region.elem) ) × synergyMult(party)
```

- **P ≥ E (승리)**: 파티 현재 HP에서 `E/P × k` 비례 피해. 포획 판정 진입(§7)
- **P < E (패주)**: 대미지 크게, 해당 조우 보상 없음. HP 0 → **전멸: 조기 귀환**, 그때까지 획득의 50%만 반입
- HP는 원정 내내 지속 감소(정령 시너지·야영 이벤트로 회복) → "얼마나 깊이 버티나"가 파티 질의 척도

### 5.4 갈림길 이벤트 (푸시 상호작용)

원정 중 정해진 시점에 발생, **푸시로 통지**:

> "원정대가 수상한 제단을 발견했습니다. 조사할까요?"

- 선택지 2개: 안전(소보상 확정) / 위험(P 검사 → 대성공 희귀 보상 or HP 대미지)
- **4시간 미응답 시 자동으로 안전 선택** (플레이어 손해 없음, 응답하면 리스크·리턴 선택권)
- v1은 갈림길 결과를 일지에서 소급 확인 + 귀환 전 앱 접속 시 선택 가능. **푸시 탭→즉답은 v1.5** (M6)

### 5.5 원정 일지 (핵심 연출)

귀환 후 열람하는 타임라인. 조우 카드가 순서대로 넘어가며:

```
🌲 속삭이는 숲 · 원정 (2시간)
├─ ⚔️ 가시덩쿨 늑대 조우 — 승리! (파티 HP -8%)
│    └─ 🎯 포획 시도... 성공! [도감 신규 등록]
├─ 💰 이끼 낀 보물상자 — 골드 +320
├─ ⚔️ 심연 두꺼비 조우 — 패주… (HP -22%) [목격 기록]
├─ 🔀 갈림길: 수상한 제단 → 조사함 — 대성공! 정령이끼 +6
└─ 🏕️ 귀환 — 총획득: 골드 1,240 · 이슬가지 ×4 · 신규 1종 · 정수 12
```

- 카드당 3초 자동 재생(스킵/한번에 보기 지원). 아이콘 흔들림·데미지 숫자·포획 구슬 연출
- Lottie는 포획 성공/레벨업/도감 마일스톤 축하에만 절제 사용

## 6. 지역 (v1: 4개 + 예약 1개)

| # | 지역 | 우세 속성 | 주 종족 | 권장 CP | 해금 조건 |
|---|---|---|---|---|---|
| 1 | 물안개 해안 | 자연 | 야수·수생 | 100 | 시작 지역 |
| 2 | 속삭이는 숲 | 자연 | 야수·비행·정령 | 400 | 해안 도감 6종 |
| 3 | 가라앉은 늪 | 냉기 | 수생·언데드 | 1,200 | 숲 도감 8종 + 재료 |
| 4 | 잿빛 화산 | 화염 | 야수·기계 | 3,000 | 늪 도감 8종 + 재료 |
| 5 | (v1.5) 별빛 폐허 | 빛/어둠 | 정령·언데드 | 8,000 | 도감 40종 |

- 지역당 몬스터 12종: 커먼 7 / 레어 3 / 에픽 2 → **v1 도감 48종 + 전설 4종(지역별 심층 한정) = 52종**
- 지역 재료 2종씩(예: 해안—소금꽃·조가비 / 숲—이슬가지·정령이끼): 미끼 제작, 다음 지역 해금, 성급 보조 재료
- 우세 속성: 해당 속성 파티원 CP ×1.3이 걸리는 지역 상성(§5.3의 elemMult) — 지역이 바뀌면 최적 편성도 바뀐다

## 7. 포획 시스템

### 7.1 판정

승리한 몬스터 조우마다 1회:

```
포획률 = 기본률(등급) × 미끼 배수 × 마일스톤 보정
기본률: 커먼 40% / 레어 15% / 에픽 5% / 전설 1.5%
```

- **미끼**: 지역 재료로 제작하는 소모품. 파견당 최대 3개 적재, 레어 이상 조우에 자동 우선 소모(정책은 콘텐츠 값). 효과: 포획률 ×2
- 실패해도 **목격 기록**(도감 실루엣 + 서식지 힌트) → "다음엔 잡는다" 동기
- 광고(IAA) 버프: 포획률 ×2, 30분 (미끼와 중첩 시 ×4 상한)

### 7.2 도감 (수집의 축)

- 종당 3단계: **목격**(실루엣) → **포획**(정보 공개) → **각성**(★3 도달, 도감 일러스트 테두리)
- 마일스톤 보상(영구 버프 + 골드): 지역 6종 / 12종 완성, 종족 5종 수집, 총 10·25·40종 등
  - 예: "해안 도감 완성 — 전 파티 HP +3%" (버프는 전부 콘텐츠 데이터)
- 도감 점수 = 목격 1 / 포획 3 / 각성 5점 합산 → (v2) 랭킹 지표

## 8. 경제

### 8.1 재화

| 재화 | 소스 | 싱크 |

| 골드 | 조우 승리, 보물, 일지 정산, 도감 보상, 광고 2배 | 레벨업(주 싱크), 슬롯 확장, 미끼 제작 부재료 |

- 첫 7일 목표 곡선: D1 해안 클리어 → D2~3 숲 → D4~6 늪(첫 벽, 시너지 학습 강제) → D7 화산 진입. M3에서 시뮬레이터로 검증

### 8.2 광고 (IAA) 배치 — 전부 보상형, 강제 없음

## 10. UX 화면 구조 (세로 · 하단 탭 4)

```
[홈]     원정 현황 카드(팀별 진행 게이지·남은 시간·갈림길 대기 뱃지) + 귀환 정산 진입
```
