> 몬스터 포획 원정 RPG · 앱인토스 미니앱 우선 · v1 기준
> 상태: **초안 (M0 리뷰 대상)** · 마지막 수정: 2026-08-22

## 1. 한 줄 정의

**미지의 신대륙 "뉴 월드"를 탐험하며 야생 몬스터를 포획해 나만의 원정대를 꾸리는 방치형 수집 RPG.**

- 장르: 방치형(파견) × 수집(도감) × 편성 퍼즐(시너지)
- 플랫폼: Google Play(Capacitor, 세로·원핸드) 1차 → 이후 앱인토스 웹 미니앱 (2026-08-22 순서 전환, 앱인토스 보류)
- 세션 패턴: 하루 3~6회, 회당 1~3분
- 아트: IconScout 3D 아이콘 (정적 오브젝트) — **전투 애니메이션이 필요 없는 설계**가 전제

### 세계관 톤

대항해시대 끝자락, 지도 밖에서 발견된 신대륙 **"뉴 월드"**. 플레이어는 탐험단의 단장이 되어
신대륙의 야생 몬스터를 포획하고 길들여, 더 깊은 미답지로 원정을 보낸다.
톤은 라이트 판타지 + 아기자기(3D 아이콘의 귀여운 렌더 톤과 일치). 텍스트는 전부 한글.

> 대안으로 검토했던 SF 외계행성 개척 테마는 몬스터 에셋 풀(판타지·할로윈 계열이 압도적)과
> 충돌해서 기각. M0 리뷰에서 뒤집을 수 있음.

## 2. 디자인 필러 (모든 결정의 기준)

1. **전투를 보여주지 않는다.** 재미의 본체는 수집·편성·성장이다. 전투는 "원정 일지"로 요약되고,
   조우 순간만 3초 컷(아이콘 흔들림 + 데미지 숫자 + 포획 이펙트)으로 연출한다.
2. **편성 화면이 메인 게임이다.** 속성 상성 × 종족 시너지 × 지역 특성 × 유물 세팅의 조합 퍼즐.
   "어느 지역에 누구를, 어떤 유물을 들려 보낼까"가 매 파견마다 유의미한 선택이어야 한다.
3. **도감이 엔드 콘텐츠다.** 목격→포획→각성 3단계 기록. 도감 진척이 곧 파워(마일스톤 영구 버프)와
   콘텐츠 해금(지역·슬롯)으로 되먹임된다.
4. **토스라서 되는 것을 쓴다.** 푸시가 게임 메커니즘이다(귀환 알림, 갈림길 이벤트, 전설의 기척).
   방치형의 고질병인 재방문 루프를 플랫폼 인프라로 해결한다.
   *(2026-08-22 주: Google Play 1차에서는 귀환 알림을 로컬 알림으로 동일 구현 — 알림 메커니즘 필러는 플랫폼 무관 유지, 서버 푸시는 앱인토스 트랙 재개 시)*
5. **모든 판정은 결정론이다.** 파견 시 시드가 확정되고 이후 모든 조우·포획·보상은 시드에서
   유도된다. 같은 입력 = 같은 일지. (서버 재검증 가능 → 랭킹 도입 시 치트 대응 경로)

## 3. 코어 루프

```
[편성] 몬스터 3~5마리 선택 (속성·시너지 퍼즐)
   ↓
[파견] 지역 × 길이(정찰 15분 / 원정 2시간 / 심층 8시간) 선택
   ↓
[방치] 실시간 경과 — 중간에 갈림길 이벤트 푸시(선택 응답)
   ↓
[귀환] 푸시 알림 → 원정 일지 열람 (조우 타임라인 리플레이)
   ↓
[획득] 포획 몬스터 도감 등록 · 전리품(골드/재료) · 유물 발굴 · 목격 기록
   ↓
[성장] 레벨업 · 성급 각성 · 유물 착용·강화 · 미끼 제작 · 도감 마일스톤
   ↓  (더 강해진 원정대로)
[해금] 더 깊은 지역 · 원정대 슬롯 · 동시 파견 팀 → 다시 [편성]
```

- **미드 루프**: 지역 도감 완성(지역당 54종), 종족 컬렉션, 시너지 조합 실험
- **롱 루프**: 전설 몬스터 24종 포획(심층 한정·지역당 6종), 전설 유물 수집·강화(종 단위 — 2026-08-23), 전 도감 완성, (v1.5+) 별빛 폐허·랭킹

## 4. 몬스터 시스템

### 4.1 개체 구성

| 항목 | 내용 |
|---|---|
| 속성 | 화염 / 자연 / 냉기 / 빛 / 어둠 — 5속성 |
| 종족 | 야수 / 정령 / 언데드 / 수생 / 비행 / 기계 — 6종족 (시너지 축) |
| 등급 | 일반 / 고급 / 희귀 / 영웅 / 전설 / **초월** — 6단계, 유물과 명칭 통일 (도감 희귀도 = 포획 난도, 2026-08-23 개편 · 2026-08-25 초월 추가) |
| 초월 | 합성으로만 도달하는 최종 등급 (2026-08-25 사용자). 조우·발굴·상점 뽑기 확률 0. 몬스터 3종·유물 4점 |
| 스탯 | HP, ATK 두 개만. 전투력 CP = ATK × 2 + HP ÷ 2 |
| 성장 | 레벨 1~30 · 성급 ★1~★5, 전부 **골드**. 성장은 **종 단위** — 같은 종 카드가 몇 장이든 레벨·성급은 종당 하나 (2026-08-23) |

스탯을 2개로 최소화한 이유: 전투를 보여주지 않으므로 스탯의 역할은 "파견 퍼즐의 숫자"다.
깊이는 스탯 개수가 아니라 상성·시너지 조합에서 나온다.

### 4.2 속성 상성 (배수)

```
화염 → 자연 → 냉기 → 화염   (삼각 순환, 유리 ×1.3 / 불리 ×0.77)
빛 ↔ 어둠                    (상호 유리 ×1.3)
그 외 조합                    ×1.0
```

지역마다 우세 속성이 있어(§6) 파티의 유효 전투력에 지역 상성 보정이 곱해진다.

### 4.3 종족 시너지 (편성 2 / 3마리 발동)

| 종족 | 2마리 | 3마리 |
|---|---|---|
| 야수 | 파티 ATK +10% | 파티 ATK +25% |
| 정령 | 조우 후 HP 5% 회복 | 조우 후 HP 12% 회복 |
| 언데드 | 전멸 피해 20% 경감 | 원정당 1회, 전멸 시 HP 30%로 부활 |
| 수생 | 늪·해안 지역 CP +15% | +30% 및 익사 함정 무효 |
| 비행 | 함정 이벤트 50% 회피 | 100% 회피 + 이동 조우 수 +1 |
| 기계 | 받는 피해 -8% | -20%, 단 정령 회복 효과 절반 |

- 수치는 전부 콘텐츠 JSON에 있으며 밸런스 시트(M3)에서 조정한다.
- 5칸 편성에서 "3+2" 이중 시너지가 이상적 조합 → 슬롯 확장의 가치를 만든다.

### 4.4 성장 곡선 (초안)

- 레벨 스탯: `stat(Lv) = base × (1 + 0.08 × (Lv - 1))` → Lv30 = base × 3.32
- 레벨업 골드: `cost(Lv) = 40 × Lv^1.5 × 지역배수 × 등급배수` *(2026-08-23 차등화)*
- 성급: ★당 스탯 ×1.25 (★5 = ×2.44). 기본 골드 1,500 / 6,000 / 20,000 / 60,000 (★2~★5) × 같은 배수
- **성장 비용 차등 (2026-08-23)** — 원정 단계가 깊을수록 성장도 비싸진다:
  지역 배수 `growthCostMult` = 해안 ×1 / 숲 ×2.4 / 늪 ×5.5 / 화산 ×12 (**rewardScale과 같은 계단** —
  "그 지역에서 벌어 그 지역 몬스터를 키우는" 체감을 일정하게), 등급 배수 = 일반 1 / 고급 1.2 / 희귀 1.5 / 영웅 2 / 전설 3.
  해안 일반은 기존 비용 그대로라 초반 곡선 불변
- 중복 포획 = 해당 종 **카드 +1** (카드 수는 도감·칩에 숫자로 표시 — 합성 재료)
- *(2026-08-23) 정수 시스템 폐기 — 성장 재화는 골드로 일원화, 로스터는 개체(uid)에서 종 단위로 통합*

### 4.4-1 모래시계 세공 (2026-08-25)

지역 재료를 **모래시계**로 바꾼다. 재료 8종(지역당 2종) 중 조가비·잿불핵·흑요석조각은 소모처가 0이었다 —
재료의 주 용도가 '다음 지역 해금'인데 화산이 마지막 지역이고, 숲 해금은 재료를 요구하지 않기 때문이다.
미끼는 파견당 3개 상한(`balance.lures.maxLoad`)이라 레시피를 늘려도 누적을 풀지 못한다.
**모래시계는 소비에 천장이 없어** 재료의 실질 소모처가 된다.

| 레시피 | 재료 | 산출 | 분/재료 |
|---|---|---|---|
| 해안의 모래 세공 | 소금꽃3 · 조가비3 | 모래시계 조각 ×8 (120분) | 20.0 |
| 숲의 모래 세공 | 이슬가지3 · 정령이끼3 | 여행자의 모래시계 ×2 (120분) | 20.0 |
| 늪의 모래 세공 | 무덤갈대3 · 한기호박3 | 은빛 모래시계 ×1 (120분) | 20.0 |
| 화산의 모래 세공 | 잿불핵6 · 흑요석조각6 | 금빛 모래시계 ×1 (240분) | 20.0 |
| 화산의 정수 세공 | 잿불핵11 · 흑요석조각11 | 황금 모래시계 ×1 (480분) | 21.8 |

- **무한 스킵 차단**: 재료 효율이 가장 좋은 티어는 심층이 아니라 **정찰**이다 —
  분당 조우 밀도가 정찰 3조우/15분 vs 심층 18조우/480분으로 3배 차이가 난다.
  정찰 기준 손익분기가 33분/재료라서 레시피를 20~22에 두어 **최소 1.4배 손해**를 보장한다.
  테스트가 세 티어를 모두 검사한다
- **효율은 분/재료 20~22로 균일** — 어느 하나가 압도적이면 나머지가 죽은 레시피가 된다
- **골드는 상점가보다 비싸다.** 골드는 이미 남아돌아(시뮬 하드코어 D5에 33만) 제동이 못 된다.
  재료 루트의 값어치는 가격이 아니라 **일일 한도가 없다**는 데 있다
  (상점 골드 모래시계는 15분×3 · 60분×2 · 120분×2 · 240분×1 · 480분×1로 하루가 묶여 있다)
- 저등급은 단축량이 작아 1개만 주면 값어치가 없으므로 묶음으로 준다 (조각 8개)

### 4.4-2 재료 수급·소비 대칭 (2026-08-25)

소모처를 붙인 뒤에도 **지역 재료 2종 중 한쪽만 쌓였다**. 원인은 수급과 소비가 서로 반대로 기울어서다.

- **수급**: 채집 조우는 지역 재료 2종을 균등 랜덤으로 준다. 그런데 갈림길 재료 보상이 슬롯 고정이었다 —
  '수상한 제단' 위험 성공이 슬롯1 ×6, '길 잃은 탐험가' 안전이 슬롯0 ×3.
  갈림길 성향은 파티 전투력이 정하므로, **강한 유저는 평생 슬롯1만** 받았다 (심층 1회 1.13 : 3.52)
- **소비**: 반대로 레시피·해금이 슬롯0을 더 요구했다 (화산 세공 4:3, 정수 8:7, 화산 해금 24:16)
- **결과**: 시뮬 14일에 흑요석조각 소비율 23%, 하루 67개씩 사장

**규칙 — 수급도 소비도 지역 재료 2종을 같은 수로 다룬다.**
갈림길 재료 보상은 한 갈래 안에서 슬롯0/슬롯1을 같은 수로 주고(제단 3+3, 탐험가 2+2),
모든 레시피·해금 비용도 2종을 같은 수로 쓴다. 소비율이 8종 모두 92~100%로 올라온다
(`scripts/material-audit.ts --days 14 [--endgame]`, 테스트 `tests/crafting.test.ts`가 대칭을 고정).

지역 해금 재료도 대칭으로 바꿨다 (늪 이슬가지16·정령이끼10 → **16·16**, 화산 무덤갈대24·한기호박16 → **24·24**).
대칭화하면 병목 재료의 수급이 2배가 되어 해금이 빨라지므로 총량을 한 번 올렸다가,
같은 날 게이트를 도감 주도로 재조정하면서(§6.1) 재료는 "제동"이 아니라 "값"으로 내렸다.

### 4.5 카드 합성 (2026-08-23)

같은 등급의 **여분 카드 2장**을 소모해 **다음 등급 몬스터 1종(랜덤)** 획득에 도전한다.
같은 등급 여분을 묶어 **일괄 합성**(횟수 선택)할 수 있고, 성공 결과는 ?카드로 나와 탭하면 공개된다.

- 재료: 같은 등급이면 종은 무관 (같은 종 2장도 가능). **각 종의 마지막 1장은 재료가 될 수 없다**
  — 육성한 몬스터가 합성으로 사라지는 사고 방지. 여분 = 보유 카드 − 1
- 성공 확률: 일반→고급 50% / 고급→희귀 25% / 희귀→영웅 12.5% / 영웅→전설 6.25% / **전설→초월 3%** (balance.json)
- 성공: **해금 지역**의 다음 등급 몬스터 중 랜덤 1종 — 미보유 종이면 도감 신규 등록(마일스톤 평가 포함),
  보유 종이면 카드 +1. 영웅→전설 합성은 심층 파밍 외의 전설 획득 경로가 된다
- 실패: 재료 2장 중 **1장은 반환** (실소모 1장 — 도전 문턱 완화, 확률 정보에 명시 공개)
- **초월 카드는 재료 불가** (다음 등급 없음 — 사다리의 종점). 판정은 ctx 시드 기반 결정론

**초월 합성 (2026-08-25 사용자 확정)** — 초월은 합성이 **유일한** 획득 경로다.

- 조우·유물 발굴·상점 뽑기 확률은 전부 0. 어느 지역의 spawns·legendary 필드에도 등장하지 않는다
- **재료는 마지막 지역(현재 잿빛 화산) 서식 전설 카드만.** 다른 지역 전설은 재료가 되지 않는다 —
  엔드콘텐츠 관문. 지역이 늘어나면(별빛 폐허 등) 관문도 자동으로 그 지역으로 옮겨간다
- 유물에는 서식 지역 개념이 없어, 대응 등가로 **마지막 지역 해금**을 조건으로 한다
- 몬스터 3종(전부 화산 서식)·**유물 4점 — 무기/방어구/깃발/부적 4슬롯을 한 점씩** (세트는 만들지 않는다).
  4슬롯을 다 채워야 초월만으로도 편성이 온전해진다.
  개수가 적은 대신 에셋 퀄리티를 최우선으로 한다

**유물 합성 (2026-08-23, 종 단위 개편 반영)** — 카드 합성과 완전히 동일한 규칙·확률.

- 재료: 같은 등급의 **여분 2개** (여분 = 보유 개수 − 1). **각 종의 마지막 1개는 재료가 될 수 없다**
  — 강화가 종에 붙으므로 육성 소실 방지(몬스터와 동일한 이유). 초월은 재료 불가(종점)
- 성공: 다음 등급 **전체 유물 풀**에서 랜덤 1종 — 보유 종이면 개수 +1, 신규면 등록(신규 표시)
- 실패: 재료 2개 중 **1개는 반환** (실소모 1개 — 카드 합성과 동일)
- 판정 스트림 분리('fusion-artifact'). 강화는 종에 남으므로 합성으로 잃을 것이 없다

## 5. 원정 시스템

### 5.1 파견 길이 3단

| 구분 | 시간 | 조우 수 | 특징 |
|---|---|---|---|
| 정찰 | 15분 | 3 | 튜토리얼·짬 플레이. 갈림길 없음 |
| 원정 | 2시간 | 8 | 표준. 갈림길 1회. 시간당 효율 ×1.2 |
| 심층 탐사 | 8시간 | 18 | 취침 전 파견. 갈림길 2회, 희귀 출현률 ×2, **전설은 심층에서만** |

- **군 시스템 (2026-08-23 개편)**: 원정대는 1~4군 **영구 프리셋** — 시작 1군 → 숲 해금 2군 → 늪 3군 → 화산 4군.
  편성은 원정 화면의 군 카드(2×2 미리보기 + CP·속성 요약)에서, 파견은 군 단위 (파견 중인 군은 재파견·편성 변경 잠금)
- 배타 규칙: 몬스터는 **종 카드 수 기준** — 카드 2장이면 두 군에 동시 편성·파견 가능, 같은 군 내 같은 종 중복 불가.
  유물은 uid 개체 단위로 한 군에만 연결 (같은 종류 여러 개면 각 군에 하나씩)

### 5.2 조우 시퀀스 생성 (결정론)

파견 확정 시 `seed`가 정해지고, 시드에서 조우 시퀀스가 유도된다:

```
각 슬롯 roll → 몬스터 조우 72% / 보물 12% / 함정 10% / 채집 6%
몬스터 조우: 지역 출현 테이블(가중치)에서 종 선정 → 난이도 E 산출
```

### 5.3 조우 판정 모델

파티 유효 전투력:

```
P = Σ_unit ( CP × elemMult(unit.elem, region.elem) ) × synergyMult(party)
```

- **P ≥ E (승리)**: 파티 현재 HP에서 `E/P × k` 비례 피해. 포획 판정 진입(§7)
- **P < E (패주)**: 대미지 크게, 해당 조우 보상 없음. HP 0 → **전멸: 조기 귀환**, 그때까지 획득의 50%만 반입
- HP는 원정 내내 지속 감소(정령 시너지·야영 이벤트로 회복) → "얼마나 깊이 버티나"가 파티 질의 척도

### 5.4 갈림길 이벤트 (푸시 상호작용)

원정 중 정해진 시점에 발생, **푸시로 통지**:

> "원정대가 수상한 제단을 발견했습니다. 조사할까요?"

- 선택지 2개: 안전(소보상 확정) / 위험(P 검사 → 대성공 희귀 보상 or HP 대미지)
- **4시간 미응답 시 자동으로 안전 선택** (플레이어 손해 없음, 응답하면 리스크·리턴 선택권)
- v1은 갈림길 결과를 일지에서 소급 확인 + 귀환 전 앱 접속 시 선택 가능. **푸시 탭→즉답은 v1.5** (M6)

### 5.5 원정 일지 (핵심 연출)

귀환 후 열람하는 타임라인. 조우 카드가 순서대로 넘어가며:

```
🌲 속삭이는 숲 · 원정 (2시간)
├─ ⚔️ 가시덩쿨 늑대 조우 — 승리! (파티 HP -8%)
│    └─ 🎯 포획 시도... 성공! [도감 신규 등록]
├─ 💰 이끼 낀 보물상자 — 골드 +320
├─ ⚔️ 심연 두꺼비 조우 — 패주… (HP -22%) [목격 기록]
├─ 🔀 갈림길: 수상한 제단 → 조사함 — 대성공! 정령이끼 +6
├─ 💎 무너진 석궤 — 유물 발굴! [영웅] 개척자의 깃발
└─ 🏕️ 귀환 — 총획득: 골드 1,240 · 이슬가지 ×4 · 신규 1종 · 카드 +2 · 유물 1
```

- 우세 속성: 해당 속성 파티원 CP ×1.3이 걸리는 지역 상성(§5.3의 elemMult) — 지역이 바뀌면 최적 편성도 바뀐다

### 6.1 해금 조건 사다리 (2026-08-25 재조정)

해금은 **도감 종 수 AND 재료 개수** 두 조건이다. 둘의 역할을 갈라 둔다:

- **도감 = 제동.** "이 지역을 얼마나 탐험했는가". 진행 속도를 정하는 건 이쪽이다
- **재료 = 값.** 문을 여는 데 치르는 비용. 제동으로 쓰지 않는다

| 관문 | 조건 | 앞 지역 54종 대비 |
|---|---|---|
| 속삭이는 숲 | 해안 도감 10종 | 19% (맛보기 — 스타터 3종이 이미 도감에 있어 실제로 7종을 잡는다) |
| 가라앉은 늪 | 숲 도감 24종 + 이슬가지·정령이끼 16개씩 | 44% (첫 벽) |
| 잿빛 화산 | 늪 도감 40종 + 무덤갈대·한기호박 24개씩 | 74% (마지막 관문) |

**왜 재료를 제동으로 쓰지 않는가** — 재료는 원정 횟수에 비례해 쌓이므로 **역진적**이다.
계측상 화산 재료 조건을 16→48개로 3배 올려도 "보통" 유저의 해금일은 D7→D8로 하루밖에 안 밀리는데,
"방치" 유저는 D14→D17로 사흘이 밀린다. 빠른 유저는 그대로 통과시키고 느린 유저만 때리는 게이트다.
반대로 도감 조건은 쿠폰 수집가 문제(이미 잡은 종은 카드만 준다) 때문에 **모두에게 체감 난도가 붙는다**.

**재조정 전에는 도감 조건이 죽어 있었다** — 8/20/20은 재료 조건보다 항상 먼저 채워져서,
실제 해금 시점을 정하는 건 늘 재료였다. 몬스터를 지역당 54종으로 확장(2026-08-24)하면서
도감 조건을 14→20으로만 올린 탓에 비율이 54%→37%로 오히려 헐거워진 게 원인이다.

측정: `npx tsx scripts/unlock-sweep.ts --days 21` (후보 비교) ·
`npx tsx scripts/simulate.ts --days 21 --gates` (병목이 도감인지 재료인지).
불변식은 `tests/content.test.ts`의 «지역 해금 조건» 블록이 고정한다 —
바로 앞 지역만 참조 / 전설 없이 달성 가능 / 비율 단조 증가 / 재료는 도감의 1.5배 이하.

## 7. 포획 시스템

### 7.1 판정

승리한 몬스터 조우마다 1회:

```
포획률 = 기본률(등급) × 미끼 배수 × 마일스톤 보정
기본률: 일반 45% / 고급 34% / 희귀 18% / 영웅 6% / 전설 1.5%
```

- **미끼**: 지역 재료로 제작하는 소모품. 파견당 최대 3개 적재, 효과 포획률 ×2. 안 쓴 미끼는 귀환 시 반환된다
  - 자동 사용 정책 (2026-08-25 개정): **아직 도감에 없는 희귀 이상** 조우에만 쓴다.
    이전에는 보유 여부를 보지 않아 늪 도감 39~41종 구간(= 화산 해금 게이트가 걸리는 구간)에서
    소모 미끼의 **약 78%가 이미 잡은 종에 버려졌다**. 이미 잡은 종에 써서 얻는 건 카드 1장뿐인데
    미끼의 값어치는 도감을 늘리는 데 있고, 해금 게이트도 도감이 정한다(§6.1)
- 실패해도 **목격 기록**(도감 실루엣 + 서식지 힌트) → "다음엔 잡는다" 동기
- 광고(IAA) 버프: 포획률 ×2, 30분 (미끼와 중첩 시 ×4 상한)

### 7.2 도감 (수집의 축)

- 도감 화면은 **몬스터 / 유물 / 업적 3탭** (2026-08-23 — 모바일 스크롤 최소화)
- 몬스터 종당 3단계: **목격**(실루엣) → **포획**(정보 공개) → **각성**(★3 도달, 도감 일러스트 테두리)
- 유물 도감(v7): 등급별 그리드, **획득 이력** 기반 — 마지막 개를 분해해 종이 사라져도 흐린 아이콘으로 남는다
- 업적 보상(골드·가루 + 일부 영구 버프): **지역당 13계단** (2/4/6/9/12/14/16/20/24/26/34/44/54종 — 2026-08-24 확장,
  버프는 기존 6/12/24 + 54종 완전 정복에만) + 공통 17종 (종족 5·8종, 총 10~216종 사다리, 초월 1·3종) = 총 69개
  - 예: "해안 도감 완성 — 전 파티 HP +3%" (버프는 전부 콘텐츠 데이터)
- **사다리는 두 축이다** (2026-08-25 사용자 결정 — 초월 3종 추가로 상한이 어긋난 걸 고치며)
  - **서식종 축** (지역 54 · 종족 · 총합 216): 출현 테이블에 실제로 등장하는 216종만 센다.
    초월은 habitat이 화산이어도 **집계에서 뺀다** — 넣으면 화산 서식종 51종 + 초월 3종으로
    "잿빛 화산 완전 정복"이 터지고, 219종 중 216종에서 "신대륙 도감의 완성"이 터진다
  - **초월 축** (초월 1종 · 3종): 합성 전용 3종을 세는 별도 계단. 전설→초월 3%에 3종 랜덤이라
    완주 기댓값이 화산 전설 스페어 약 189장(영웅 카드 환산 약 12,800장)이다 —
    도감 완주와 자릿수가 달라서, 완성 조건에 섞지 않고 **엔드콘텐츠 축으로 분리**했다
  - 초월 계단 보상은 골드·가루만 준다. 초월 몬스터 자체가 이미 강한 고유 능력(공/체 +20%,
    시너지 증폭 +30%, 보상 +20%)을 들고 오므로 그 위에 영구 버프를 또 얹지 않는다
  - 도감 화면의 몬스터 탭은 그대로 **219종 기준**으로 보여준다 (잡은 걸 안 보여줄 이유는 없다).
    사다리의 모수만 축별로 갈린다
  - 두 축의 꼭대기가 각자 모수와 정확히 같은지는 `tests/content.test.ts`가 고정한다 —
    종을 늘리면서 사다리를 안 늘리면 빨개진다
- 도감 점수 = 목격 1 / 포획 3 / 각성 5점 합산 → (v2) 랭킹 지표

## 8. 유물 시스템 (전리품 파밍)

원정의 전리품 축. "신대륙 유적에서 유물을 발굴해 원정대를 무장시킨다."
설계 목표: **아이템의 다양성과 고유 능력이 게임의 변수를 만든다.** 능력은 코드가 아니라
훅 기반 데이터로 정의해(스키마: DATA §1.5) 콘텐츠 추가만으로 계속 확장한다.

### 8.1 착용 구조 — 팀 단위 4슬롯

| 슬롯 | 정체성 | 주옵션 경향 |
|---|---|---|
| 무기 | 공격 | 파티 ATK% |
| 방어구 | 생존 | 파티 HP%·피해 경감 |
| 깃발 | 시너지·광역 | 시너지 증폭, 파티 광역 효과 |
| 부적 | 유틸 | 포획·탐사·보상 |

- **몬스터 개체별이 아니라 팀 프리셋에 장착.** 216마리 × 슬롯의 인벤토리 관리 지옥을 피하고,
  장비 선택이 편성 퍼즐(필러 2)의 한 층으로 통합된다
- 동시 파견 팀이 늘수록(1→4군) 필요한 세트가 늘어 파밍 수요가 자연 확장 — **같은 종을 2개 모으면
  두 군에 동시 장착 가능** (종 단위 개수 배타, 몬스터 카드와 동일 — 2026-08-23)
- 파견 배타도 개수 기반: 사용 중 수 + 1 > 보유 수면 파견 불가. 강화·분해는 파견 중에도 허용
  (강화가 종에 붙어 개체 잠금이 무의미 — 몬스터 레벨업과 동일 규칙)

### 8.2 등급과 옵션 — 파밍 동기의 핵

**유물은 몬스터처럼 종 단위다 (2026-08-23 v6 개편 — 부옵션 폐지).** 같은 유물을 중복 획득하면
개수가 쌓이고, 강화는 종당 하나로 공유한다. 개체 굴리기(부옵션 롤) 대신 **개수 수집**이 파밍 동기:

#### 9.1-1 목표 곡선의 기준선 문제 (2026-08-25 계측)

**§9.1의 목표 곡선은 "상점을 한 번도 안 쓰는 봇"으로 잡혔다.** simulate.ts의 봇은 골드 상점을
이용하지 않고, 미끼를 3개만 들고(파견당 적재 상한이 3이라 **2군부터는 맨몸으로 나간다**),
모래시계를 사지도 쓰지도 않으며, 월간 출석도 하지 않는다. 실유저는 이 중 아무것도 안 할 이유가 없다.

같은 "보통"(하루 4회) 유저를 행동만 바꿔 재보면 (`scripts/spend-sim.ts --ablation`):

| 행동 | 숲 | 늪 | 화산 |
|---|---|---|---|
| ① 기본 봇 (= §9.1 목표 곡선의 기준) | D1 | D6 | D9 |
| ② + 미끼를 팀 수만큼 확보 | D1 | D6 | D10 |
| ③ + 골드 상점 일일 한도까지 | D2 | D7 | D10 |
| ④ + 보유 모래시계 사용 | D2 | D6 | D8 |
| ⑤ + 재료를 모래시계로 세공 | D2 | D5 | D8 |
| ⑥ + 월간 출석 (= **무과금 최선**) | D2 | D5 | D7 |

*(슬롯 게이트까지 합친 2026-08-25 통합 상태 기준)*

즉 **무과금이라도 제대로 놀면 화산이 D7**이고, 목표창(D10~14)보다 3일 빠르다.
가장 큰 레버는 ④(모래시계를 실제로 쓰는 것)다.

**가장 크게 뒤집히는 건 방치다.** 기본 봇으로는 늪 D17·화산 D25인데, 상점 모래시계를 챙기면
**늪 D9·화산 D13**이 된다 — 약한 파티를 상점 시간으로 벌충하기 때문이다.
슬롯 게이트가 방치에 준 타격은 "게임을 아는 유저"에겐 절반쯤 상쇄된다.

두 가지 함정이 계측 중에 드러났다:

- **제작이 해금 재료를 잠식한다** — 모래시계 세공도 미끼 꾸러미도 다음 지역 해금과 **같은 재료 풀**을 먹는다.
  아무 생각 없이 다 만들면 화산 해금이 D7 → D19로 밀린다.
  → **해결 (2026-08-25)**: 캠프 제작 화면이 "만들면 해금분이 모자랍니다 (제작 후 n/필요)"로 알린다.
  막지는 않는다 — 지금 시간을 벌지 나중에 문을 열지는 유저가 고를 문제다
- **미끼가 이미 포획한 종에도 쓰였다** (`expedition.ts`가 `alreadyCaptured`를 계산해 놓고
  `shouldUseLure`에 넘기지 않았다). 늪 도감 39~41종 구간에서 소모 미끼의 약 78%가 낭비됐다.
  → **해결 (2026-08-25)**: §7.1 정책 개정. 미포획 종에만 쓴다

**결론**: 목표 곡선을 다시 잡을 때는 ①이 아니라 ⑥을 기준선으로 삼아야 한다.

#### 9.1-2 과금 구간별 진행 속도 (2026-08-25 계측)

**전제**: IAP는 아직 없다(§9.1 다이아 항 · M6 예정). **광고(IAA)도 코드에 없다** —
`balance.ads.daily`와 `adBuffMult:2`, zod 선언은 있지만 런타임 참조가 0이고
`capture.ts`의 `buffMult`에는 프로덕션에서 리터럴 1만 들어간다. 즉 §9.2는 아직 설계 문서일 뿐이다.
따라서 아래는 **충전이 붙었다고 가정한** 추정이다.

다이아 단가는 **뽑기 1회당 원화**로 역산했다. 재화 1개당 단가는 게임마다 8배씩 흩어지지만
(명일방주 2.5원 · 블루아카이브 15원 · 원신 20원) 뽑기 1회 비용으로 정규화하면 1,500~2,400원에 수렴한다.
이 게임의 몬스터 뽑기가 30💎이므로 **1💎 = 50원**이면 1,500원 — 대역 하단이고 방치형이니 하단이 맞다.
*(주의: 이 대역은 최대 패키지 기준이다. 월정액을 끼면 실효 단가가 4~7배 좋아지므로 50원은 보수적 가정이다.)*

지역 해금 일차 — 상점·출석을 챙기는 실유저 모델, 시드 5개 중앙값
(`npx tsx scripts/spend-sim.ts --days 35 --seeds 5`):

| 접속 유형 | 무과금 (월 160💎) | 월 1만원 (350💎) | 월 5만원 (1,200💎) | 월 20만원 (4,460💎) |
|---|---|---|---|---|
| 하드코어 (2시간마다) | 숲 D1 · 늪 D3 · 화산 D4 | D1 · D3 · D4 | D1 · D3 · D4 | D1 · D2 · D3 |
| **보통 (하루 4회)** | **D2 · D4 · D6** | D2 · D4 · D7 | D1 · D4 · D6 | D1 · D2 · D4 |
| 방치 (하루 2회) | D3 · D9 · D13 | D3 · D9 · D13 | D2 · D8 · D12 | D1 · D4 · D7 |

**과금이 진행 속도를 거의 못 산다.** 월 5만원은 무과금과 사실상 동일하고, 월 20만원을 써야
화산이 2~3일 당겨진다. 반대로 **접속 빈도는 훨씬 크게 작용한다** —
무과금 하드코어(화산 D4)가 월 20만원 방치(D7)보다 빠르다.

- 다이아를 **시간(모래시계)** 에 쓰는 쪽이 **도감(고급 뽑기)** 보다 빨랐다(`--policy time` vs `codex`).
  뽑기는 풀이 "해금한 모든 지역"이라 원하는 지역을 노릴 수 없고 중복이 많다
- Pay-to-win이 없다는 점에서는 건강하지만, 뒤집으면 **과금 동기가 없다**는 뜻이기도 하다.
  방치형 정석(월정액 패스·시즌 패스)을 붙일지는 미결 — 현재는 v1 범위 밖(§12)

측정: `scripts/spend-sim.ts` (구간별) · `scripts/gate-interaction.ts` (게이트가 겹칠 때의 상호작용).
**게이트를 건드린 변경이 둘 이상 쌓이면 각자 잰 값은 무효다** — 합친 상태에서 다시 재고 이 절을 갱신할 것.

### 9.3 랭킹·반복 과업 (2026-08-23)

**랭킹** — 첫 온라인 기능. 카테고리: 원정 / 몬스터 / 유물 / 과업 / 전투력 → 종합 (부자·합성·전설은 제외 결정).
점수는 전부 세이브에서 파생하며(최고 전투력만 기록값), 산식은 `core/score.ts`가 진실:

- 몬스터: 등급점(10/20/40/80/200) × 지역 배수(order 1~4) + 레벨당 5%·성급당 50% 가산. 도감·상세에 종별 점수 노출
- 유물: 등급점 + 강화 단계당 20%
- 원정: 완료당 정찰 1 · 원정 6 · 심층 30점, 전멸 귀환은 절반
- 과업: 반복 달성 횟수 × 과업별 점수
- 종합 = 원정 + 몬스터 + 유물 + 과업×2 + 전투력÷10

**반복 과업** — 업적(마일스톤, 1회성·영구 버프)과 별개의 카운터 기반 무한 반복 축 (tasks.json).
원정 5회 / 포획 20회 / 제작 10회 / 합성 5회마다 소모 재화(골드·가루)만 자동 지급 — 버프 중첩 방지.

**서버** — Supabase(rank_scores + rank_board 뷰, RLS로 원본 차단). 쓰기는 submit-score 엣지 함수만:
익명 신원(playerId + secret 해시, 세이브 v3에 저장 — 내보내기로 기기 이동)과 점수 상한을 검증.
로컬 게임 특성상 위조 원천 차단은 불가 — v1 소프트 신뢰, 상금 랭킹 금지 전제. 추후 구글 SNS 로그인 연동 예정.
제출은 원정 정산·닉네임 변경·랭킹 열람 시 자동, 실패는 조용히 무시 (게임은 완전 오프라인 동작).

### 9.4 상점 (2026-08-23)

골드/다이아 2관, 진입은 상단바 🏪 (전체 화면). **모든 상품에 구매 한도** — 컨텐츠 급속 소모 방지.
상품·가격·한도는 shop.json, 뽑기 확률표는 balance.shop (확률 정보 시트에 공개 — 확률형 아이템 고지 의무).

- 골드 상점 (10종): 미끼·지역 재료(해금 지역 전부 각 n개)·가루·몬스터 뽑기(저등급 위주)·유물 발굴
  + **모래시계 5종**(15/60/120/240/480분) — **골드의 주 소모처**.
  일일 한도를 다 쓰면 하루 9,450골드로 원정 시간 1,125분(18.75시간)을 산다
- 다이아 상점 (16종): 시작 패키지(계정 1회)·지역 개척 패키지·골드 꾸러미 3종·가루·미끼 꾸러미·
  몬스터 뽑기/고급(희귀+ 확정)·유물 발굴/고급 + 모래시계 5종
  *(원정 신속 완료는 2026-08-23에 폐지 — 가속은 모래시계로 일원화)*
- 한도 종류: daily(로컬 자정 리셋) / once / oncePerRegion. 진행도(슬롯·해금) 직접 판매는 금지
- 다이아(💎): v4 지갑 신설. **충전(IAP)은 M6 Google Play Billing** — 그 전 유일 획득처는 월간 출석

**월간 출석 (2026-08-23, 세이브 v8)** — 상단바 📅(미수령 시 빨간 점) → 이번 달 달력에 도장.
- 보상은 날짜가 아니라 **그 달의 n번째 출석** 순서 — 며칠 빠져도 사다리를 계속 탄다 (유저 친화)
- 표는 28칸(2월에도 완주 가능), 29~31일 출석은 도장만. 매월 1일 로컬 자정 리셋 (상점 일일 한도와 동일 규약)
- 보상: 골드·가루·미끼 + **다이아 데이 6회(3·7·14·21·28일차 등, 월 합계 💎 160)** — balance.json attendance
- 뽑기: 시드 결정론('shop' 스트림). 몬스터 뽑기는 해금 지역 풀, 신규면 도감 등록 + 마일스톤 평가
