# NewWorld — 게임 설계서 (GDD)

> 몬스터 포획 원정 RPG · 앱인토스 미니앱 우선 · v1 기준
> 상태: **초안 (M0 리뷰 대상)** · 마지막 수정: 2026-08-22

## 1. 한 줄 정의

**미지의 신대륙 "뉴 월드"를 탐험하며 야생 몬스터를 포획해 나만의 원정대를 꾸리는 방치형 수집 RPG.**

- 장르: 방치형(파견) × 수집(도감) × 편성 퍼즐(시너지)
- 플랫폼: Google Play(Capacitor, 세로·원핸드) 1차 → 이후 앱인토스 웹 미니앱 (2026-08-22 순서 전환, 앱인토스 보류)
- 세션 패턴: 하루 3~6회, 회당 1~3분
- 아트: IconScout 3D 아이콘 (정적 오브젝트) — **전투 애니메이션이 필요 없는 설계**가 전제

### 세계관 톤

대항해시대 끝자락, 지도 밖에서 발견된 신대륙 **"뉴 월드"**. 플레이어는 탐험단의 단장이 되어
신대륙의 야생 몬스터를 포획하고 길들여, 더 깊은 미답지로 원정을 보낸다.
톤은 라이트 판타지 + 아기자기(3D 아이콘의 귀여운 렌더 톤과 일치). 텍스트는 전부 한글.

> 대안으로 검토했던 SF 외계행성 개척 테마는 몬스터 에셋 풀(판타지·할로윈 계열이 압도적)과
> 충돌해서 기각. M0 리뷰에서 뒤집을 수 있음.

## 2. 디자인 필러 (모든 결정의 기준)

1. **전투를 보여주지 않는다.** 재미의 본체는 수집·편성·성장이다. 전투는 "원정 일지"로 요약되고,
   조우 순간만 3초 컷(아이콘 흔들림 + 데미지 숫자 + 포획 이펙트)으로 연출한다.
2. **편성 화면이 메인 게임이다.** 속성 상성 × 종족 시너지 × 지역 특성 × 유물 세팅의 조합 퍼즐.
   "어느 지역에 누구를, 어떤 유물을 들려 보낼까"가 매 파견마다 유의미한 선택이어야 한다.
3. **도감이 엔드 콘텐츠다.** 목격→포획→각성 3단계 기록. 도감 진척이 곧 파워(마일스톤 영구 버프)와
   콘텐츠 해금(지역·슬롯)으로 되먹임된다.
4. **토스라서 되는 것을 쓴다.** 푸시가 게임 메커니즘이다(귀환 알림, 갈림길 이벤트, 전설의 기척).
   방치형의 고질병인 재방문 루프를 플랫폼 인프라로 해결한다.
   *(2026-08-22 주: Google Play 1차에서는 귀환 알림을 로컬 알림으로 동일 구현 — 알림 메커니즘 필러는 플랫폼 무관 유지, 서버 푸시는 앱인토스 트랙 재개 시)*
5. **모든 판정은 결정론이다.** 파견 시 시드가 확정되고 이후 모든 조우·포획·보상은 시드에서
   유도된다. 같은 입력 = 같은 일지. (서버 재검증 가능 → 랭킹 도입 시 치트 대응 경로)

## 3. 코어 루프

```
[편성] 몬스터 3~5마리 선택 (속성·시너지 퍼즐)
   ↓
[파견] 지역 × 길이(정찰 15분 / 조사 2시간 / 탐사 4시간 / 원정=심층 8시간) 선택
   ↓
[방치] 실시간 경과 — 중간에 갈림길 이벤트 푸시(선택 응답)
   ↓
[귀환] 푸시 알림 → 원정 일지 열람 (조우 타임라인 리플레이)
   ↓
[획득] 포획 몬스터 도감 등록 · 전리품(골드/재료) · 유물 발굴 · 목격 기록
   ↓
[성장] 레벨업 · 성급 각성 · 유물 착용·강화 · 미끼 제작 · 도감 마일스톤
   ↓  (더 강해진 원정대로)
[해금] 더 깊은 지역 · 원정대 슬롯 · 동시 파견 팀 → 다시 [편성]
```

- **미드 루프**: 소지역 도감 완성(소지역당 18종·권역당 54종 — 2026-08-26 12지역), 종족 컬렉션, 시너지 조합 실험
- **롱 루프**: 전설 몬스터 24종 포획(심층 한정·소지역당 2종), 전설 유물 수집·강화(종 단위 — 2026-08-23), 전 도감 완성, (v1.5+) 별빛 폐허·랭킹

## 4. 몬스터 시스템

### 4.1 개체 구성

| 항목 | 내용 |
|---|---|
| 속성 | 화염 / 자연 / 냉기 / 빛 / 어둠 — 5속성 |
| 종족 | 야수 / 정령 / 언데드 / 수생 / 비행 / 기계 — 6종족 (시너지 축) |
| 등급 | 일반 / 고급 / 희귀 / 영웅 / 전설 / **초월** — 6단계, 유물과 명칭 통일 (도감 희귀도 = 포획 난도, 2026-08-23 개편 · 2026-08-25 초월 추가) |
| 초월 | 합성으로만 도달하는 최종 등급 (2026-08-25 사용자). 조우·발굴·상점 뽑기 확률 0. 몬스터 3종·유물 4점 |
| 스탯 | HP, ATK 두 개만. 전투력 CP = ATK × 2 + HP ÷ 2 |
| 성장 | 레벨 1~30 · 성급 ★1~★5, 전부 **골드**. 성장은 **종 단위** — 같은 종 카드가 몇 장이든 레벨·성급은 종당 하나 (2026-08-23) |

스탯을 2개로 최소화한 이유: 전투를 보여주지 않으므로 스탯의 역할은 "파견 퍼즐의 숫자"다.
깊이는 스탯 개수가 아니라 상성·시너지 조합에서 나온다.

### 4.2 속성 상성 (배수)

```
화염 → 자연 → 냉기 → 화염   (삼각 순환, 유리 ×1.3 / 불리 ×0.77)
빛 ↔ 어둠                    (상호 유리 ×1.3)
그 외 조합                    ×1.0
```

지역마다 우세 속성이 있어(§6) 파티의 유효 전투력에 지역 상성 보정이 곱해진다.

### 4.3 종족 시너지 (편성 2 / 3마리 발동)

| 종족 | 2마리 | 3마리 |
|---|---|---|
| 야수 | 파티 ATK +10% | 파티 ATK +25% |
| 정령 | 조우 후 HP 5% 회복 | 조우 후 HP 12% 회복 |
| 언데드 | 전멸 피해 20% 경감 | 원정당 1회, 전멸 시 HP 30%로 부활 |
| 수생 | 늪·해안 지역 CP +15% | +30% 및 익사 함정 무효 |
| 비행 | 함정 이벤트 50% 회피 | 100% 회피 + 이동 조우 수 +1 |
| 기계 | 받는 피해 -8% | -20%, 단 정령 회복 효과 절반 |

- 수치는 전부 콘텐츠 JSON에 있으며 밸런스 시트(M3)에서 조정한다.
- 5칸 편성에서 "3+2" 이중 시너지가 이상적 조합 → 슬롯 확장의 가치를 만든다.

### 4.4 성장 곡선 (초안)

- 레벨 스탯: `stat(Lv) = base × (1 + 0.08 × (Lv - 1))` → Lv30 = base × 3.32
- 레벨업 골드: `cost(Lv) = 40 × Lv^1.5 × 지역배수 × 등급배수` *(2026-08-23 차등화)*
- 성급: ★당 스탯 ×1.25 (★5 = ×2.44). 기본 골드 1,500 / 6,000 / 20,000 / 60,000 (★2~★5) × 같은 배수
- **성장 비용 차등 (2026-08-23)** — 원정 단계가 깊을수록 성장도 비싸진다:
  지역 배수 `growthCostMult` = 해안 ×1 / 숲 ×2.4 / 늪 ×5.5 / 화산 ×12 (**rewardScale과 같은 계단** —
  "그 지역에서 벌어 그 지역 몬스터를 키우는" 체감을 일정하게), 등급 배수 = 일반 1 / 고급 1.2 / 희귀 1.5 / 영웅 2 / 전설 3.
  해안 일반은 기존 비용 그대로라 초반 곡선 불변
- 중복 포획 = 해당 종 **카드 +1** (카드 수는 도감·칩에 숫자로 표시 — 합성 재료)
- *(2026-08-23) 정수 시스템 폐기 — 성장 재화는 골드로 일원화, 로스터는 개체(uid)에서 종 단위로 통합*

### 4.4-1 모래시계 세공 (2026-08-25)

지역 재료를 **모래시계**로 바꾼다. 재료 8종(지역당 2종) 중 조가비·잿불핵·흑요석은 소모처가 0이었다 —
재료의 주 용도가 '다음 지역 해금'인데 화산이 마지막 지역이고, 숲 해금은 재료를 요구하지 않기 때문이다.
미끼는 파견당 3개 상한(`balance.lures.maxLoad`)이라 레시피를 늘려도 누적을 풀지 못한다.
**모래시계는 소비에 천장이 없어** 재료의 실질 소모처가 된다.

| 레시피 | 재료 | 산출 | 분/재료 |
|---|---|---|---|
| 해안의 모래 세공 | 소금꽃3 · 조가비3 | 모래시계 조각 ×8 (120분) | 20.0 |
| 숲의 모래 세공 | 이슬가지3 · 정령이끼3 | 여행자의 모래시계 ×2 (120분) | 20.0 |
| 늪의 모래 세공 | 무덤갈대3 · 한기호박3 | 은빛 모래시계 ×1 (120분) | 20.0 |
| 화산의 모래 세공 | 잿불핵6 · 흑요석6 | 금빛 모래시계 ×1 (240분) | 20.0 |
| 화산의 정수 세공 | 잿불핵11 · 흑요석11 | 황금 모래시계 ×1 (480분) | 21.8 |

- **무한 스킵 차단**: 재료 효율이 가장 좋은 티어는 심층이 아니라 **정찰**이다 —
  분당 조우 밀도가 정찰 3조우/15분 vs 심층 18조우/480분으로 3배 차이가 난다.
  정찰 기준 손익분기가 33분/재료라서 레시피를 20~22에 두어 **최소 1.4배 손해**를 보장한다.
  테스트가 세 티어를 모두 검사한다
- **효율은 분/재료 20~22로 균일** — 어느 하나가 압도적이면 나머지가 죽은 레시피가 된다
- **골드는 상점가보다 비싸다.** 골드는 이미 남아돌아(시뮬 하드코어 D5에 33만) 제동이 못 된다.
  재료 루트의 값어치는 가격이 아니라 **일일 한도가 없다**는 데 있다
  (상점 골드 모래시계는 15분×3 · 60분×2 · 120분×2 · 240분×1 · 480분×1로 하루가 묶여 있다)
- 저등급은 단축량이 작아 1개만 주면 값어치가 없으므로 묶음으로 준다 (조각 8개)

### 4.4-2 재료 수급·소비 대칭 (2026-08-25)

소모처를 붙인 뒤에도 **지역 재료 2종 중 한쪽만 쌓였다**. 원인은 수급과 소비가 서로 반대로 기울어서다.

- **수급**: 채집 조우는 지역 재료 2종을 균등 랜덤으로 준다. 그런데 갈림길 재료 보상이 슬롯 고정이었다 —
  '수상한 제단' 위험 성공이 슬롯1 ×6, '길 잃은 탐험가' 안전이 슬롯0 ×3.
  갈림길 성향은 파티 전투력이 정하므로, **강한 유저는 평생 슬롯1만** 받았다 (심층 1회 1.13 : 3.52)
- **소비**: 반대로 레시피·해금이 슬롯0을 더 요구했다 (화산 세공 4:3, 정수 8:7, 화산 해금 24:16)
- **결과**: 시뮬 14일에 흑요석 소비율 23%, 하루 67개씩 사장

**규칙 — 수급도 소비도 지역 재료 2종을 같은 수로 다룬다.**
갈림길 재료 보상은 한 갈래 안에서 슬롯0/슬롯1을 같은 수로 주고(제단 3+3, 탐험가 2+2),
모든 레시피·해금 비용도 2종을 같은 수로 쓴다. 소비율이 8종 모두 92~100%로 올라온다
(`scripts/material-audit.ts --days 14 [--endgame]`, 테스트 `tests/crafting.test.ts`가 대칭을 고정).

지역 해금 재료도 대칭으로 바꿨다 (늪 이슬가지16·정령이끼10 → **16·16**, 화산 무덤갈대24·한기호박16 → **24·24**).
대칭화하면 병목 재료의 수급이 2배가 되어 해금이 빨라지므로 총량을 한 번 올렸다가,
같은 날 게이트를 도감 주도로 재조정하면서(§6.1) 재료는 "제동"이 아니라 "값"으로 내렸다.

### 4.5 카드 합성 (2026-08-23)

같은 등급의 **여분 카드 2장**을 소모해 **다음 등급 몬스터 1종(랜덤)** 획득에 도전한다.
같은 등급 여분을 묶어 **일괄 합성**(횟수 선택)할 수 있고, 성공 결과는 ?카드로 나와 탭하면 공개된다.

- 재료: 같은 등급이면 종은 무관 (같은 종 2장도 가능). **각 종의 마지막 1장은 재료가 될 수 없다**
  — 육성한 몬스터가 합성으로 사라지는 사고 방지. 여분 = 보유 카드 − 1
- 성공 확률: 일반→고급 50% / 고급→희귀 25% / 희귀→영웅 12.5% / 영웅→전설 **4%** / **전설→초월 3%** (balance.json)
  *(영웅→전설은 2026-08-26 6.25%→4% — 12지역 개편으로 소지역 전설 풀이 2종이 되며 심층 조우
  타겟팅이 3배 정밀해져, 도감 수명(§9.5)이 219~300일 → 105~185일로 붕괴한 것을 복원하는 감속.
  같은 이유로 심층 legendaryChance 5% → 2%: 구 6종 풀의 종당 조우율 0.83%/런과 등가)*
- 성공: **해금 지역**의 다음 등급 몬스터 중 랜덤 1종 — 미보유 종이면 도감 신규 등록(마일스톤 평가 포함),
  보유 종이면 카드 +1. 영웅→전설 합성은 심층 파밍 외의 전설 획득 경로가 된다
- 실패: 재료 2장 중 **1장은 반환** (실소모 1장 — 도전 문턱 완화, 확률 정보에 명시 공개)
- **초월 카드는 재료 불가** (다음 등급 없음 — 사다리의 종점). 판정은 ctx 시드 기반 결정론

**초월 합성 (2026-08-25 사용자 확정)** — 초월은 합성이 **유일한** 획득 경로다.

- 조우·유물 발굴·상점 뽑기 확률은 전부 0. 어느 지역의 spawns·legendary 필드에도 등장하지 않는다
- **재료는 마지막 권역(현재 화산 권역) 서식 전설 카드만.** 다른 권역 전설은 재료가 되지 않는다 —
  엔드콘텐츠 관문. 권역이 늘어나면(별빛 폐허 등) 관문도 자동으로 그 권역으로 옮겨간다.
  *(2026-08-26 12지역: "마지막 소지역"으로 좁히면 재료 풀이 전설 6종→2종으로 조여져 권역 단위가 정본 — core/economy.ts finalTier)*
- 유물에는 서식 지역 개념이 없어, 대응 등가로 **마지막 권역 진입(잿빛 화산 해금)**을 조건으로 한다
- 몬스터 3종(전부 분화구 심장부 서식)·**유물 4점 — 무기/방어구/깃발/부적 4슬롯을 한 점씩** (세트는 만들지 않는다).
  4슬롯을 다 채워야 초월만으로도 편성이 온전해진다.
  개수가 적은 대신 에셋 퀄리티를 최우선으로 한다

**유물 합성 (2026-08-23, 종 단위 개편 반영)** — 카드 합성과 완전히 동일한 규칙·확률.

- 재료: 같은 등급의 **여분 2개** (여분 = 보유 개수 − 1). **각 종의 마지막 1개는 재료가 될 수 없다**
  — 강화가 종에 붙으므로 육성 소실 방지(몬스터와 동일한 이유). 초월은 재료 불가(종점)
- 성공: 다음 등급 **전체 유물 풀**에서 랜덤 1종 — 보유 종이면 개수 +1, 신규면 등록(신규 표시)
- 실패: 재료 2개 중 **1개는 반환** (실소모 1개 — 카드 합성과 동일)
- 판정 스트림 분리('fusion-artifact'). 강화는 종에 남으므로 합성으로 잃을 것이 없다

### 4.6 영구 보너스 — 조련·공명 (2026-08-25)

**육성이 계정 전체의 킥이 되게 한다** (2026-08-25 사용자 발제) — 어떤 몬스터를 키우든, 어떤 유물을
강화하든 그 투자 총량이 계단을 오르며 계정 전역 보너스로 돌아온다. 개별 CP 성장(§4.4)에 얹히는
두 번째 보상층으로, "육성할수록 모든 원정대가 세진다"를 만든다.

- **🐾 조련** (몬스터 축): 점수 = Σ(레벨−1) + 10×Σ(성급−1), 전 종 합산. **20계단** —
  효과는 전투 정체성: 공격·생명 배수, 받는 피해 감소, 원정당 조우 +1 (총합 공 +18% / 생 +18% / 피해 −10% / 조우 +3)
- **🔮 공명** (유물 축): 점수 = Σ강화(종 공통 0~5), 전 종 합산. **15계단** —
  효과는 탐험 정체성: 포획률, 골드 보상, 희귀 이상 조우 가중 (총합 포획 +6%p / 골드 +16% / 희귀 가중 ×1.6)
- 계단은 초반 촘촘·후반 장기 (2026-08-25 사용자: **완주 6개월~1년 목표**) — 조련 최종 8,000점
  (최적 경로 22.6M 골드 ≈ 보통 유저 D159, 현실 플레이 8~12개월), 공명 최종 400점(상한 500의 80%,
  최적 42k 가루 ≈ 6~9개월). 근거 곡선: 조련 4,000=D34 · 6,000=D77 · 8,000=D159 · 10,000=D307.
  계단·효과 전부 `balance.json accountBonus` 데이터라 재조정은 데이터 수정으로 끝난다
- **저장하지 않는다** — 마일스톤 버프(§7.2)와 동일하게 세이브에서 재계산, `collectTeamEffects`가
  `account:` 출처로 주입. 세이브 마이그레이션 불필요, 모든 군·모든 원정에 자동 적용
- 계단 달성 순간 토스트 (레벨업·각성·강화 직후) — 킥의 피드백. UI는 캠프 상단 카드 → 시트(사다리 전체)
- 조우 계획을 바꾸는 효과(encounterAdd·spawnWeightMult)도 안전 — 계획은 정산 시점에 한 번만
  확정되므로 파견 중 계단이 올라도 모순이 없다. 파견 정보줄의 조우 수는 보너스를 합산해 표기
- 시뮬 봇은 육성을 거의 안 해 진행 곡선(§9.1)은 사실상 불변 — 실유저는 이 보너스만큼 빨라진다

### 5.1 파견 길이 4단 (2026-08-29 탐사 신설 + 표기 개편)

| 구분 (내부 키) | 시간 | 조우 수 | 특징 |
|---|---|---|---|
| 정찰 (scout) | 15분 | 3 | 튜토리얼·짬 플레이. 갈림길 없음. 완주 시 **전설의 흔적** 15% |
| 조사 (standard) | 2시간 | 8 | 표준. 갈림길 1회. 보상 ×1.2. 흔적 25% |
| 탐사 (extended) | 4시간 | 12 | 반나절 슬롯 — 등교·출근 공백을 받는다. 갈림길 1회, 희귀 ×1.5, 보상 ×1.28. 흔적 35% |
| 원정 (deep) | 8시간 | 18 | 취침 전 파견. 갈림길 2회, 희귀 ×2, 완주 상자, **전설은 심층에서만** (흔적 없음) |

> **표기 개편 (2026-08-29)**: 버튼 4개가 한 줄에 들어가도록 정찰/조사/탐사/원정 2자 표기로 통일
> (구 명칭: 원정→조사, 심층 탐사→원정). **문서 본문의 "심층"은 deep(8시간) 티어를 가리킨다** —
> 역사적 서술이 많아 문서 용어는 유지한다. 화면 문자열의 정본은 ui/kit.ts TIER_NAME/TIER_LABEL.

#### 전설의 흔적 (2026-08-29)

낮의 정찰 스팸과 밤의 심층 전설 게이트를 **경쟁이 아닌 협력 관계**로 잇는 다리.
계기: "열심히 하는 유저는 15분을 많이 쓰는데 전설은 8시간에만 있어 형평성이 어긋나 보인다"(사용자) —
수치상으론 정찰이 조우 밀도 5배 + 합성 캐스케이드로 이미 유리하지만, 체감이 문제였다.
전설 공급률을 직접 푸는 대신(잭팟→그라인드 붕괴) 낮 활동이 밤 확률을 올리게 한다.

- **적립**: 전설 없는 티어의 **완주**(전멸 제외)마다 흔적 1개 발견 — 정찰 15% · 조사 25% · 탐사 35%
  (2026-08-29 사용자: 정찰 한정에서 확대). 회당 확률은 긴 파견이 높지만 시간당 기대치는
  정찰 0.6/h ≫ 조사 0.125/h > 탐사 0.0875/h — 능동 플레이 우위 유지. deep은 0:
  전설을 직접 만나는 파견이 흔적까지 얻으면 자기 강화 루프가 된다. (시드 파생 — 결정론)
- **소모**: 심층(deep) **출발 시** 전량 소모, 전설 조우율 개당 +1%p (기본 2% → 최대 6%)
- **상한/소멸**: 최대 4개 인정(초과분 소실), 발견 후 24시간 지나면 소멸
- 소모가 정산이 아닌 **출발 시점**인 이유: 8시간 뒤 정산 때는 TTL이 지나 있을 수 있다
  (취침 파견이 표준 사용례). 가산은 expedition.legendBonus로 확정 — 미리보기·정산이 같은 값
- 파라미터는 balance.legendTraces (dropChance/bonusPerTrace/maxStacks/ttlHours)
- 경제 영향: 심층 직접 조우는 전설 획득의 종속 경로(§6.5 — 1장당 심층 1,667회)라 3배가 돼도
  공급 곡선은 사실상 불변. 가치는 "오늘 밤 심층" 리추얼의 강화와 체감 형평성이다

- **군 시스템 (2026-08-23 개편 · 2026-08-26 게이트 이동)**: 원정대는 1~4군 **영구 프리셋** —
  시작 1군 → 숲(권역 진입) 2군 → 얼어붙은 심연 3군 → 분화구 심장부 4군.
  3·4군을 권역 진입에 두면 병렬 포획이 후반 도감 관문을 이틀 만에 뚫어 게이트가 죽는다(계측) —
  심부 배치라 4군은 사실상 "지도를 완성한 보상"이고, 그때부터 도감 완성(롱 루프)의 가속 장치가 된다.
  편성은 원정 화면의 군 카드(2×2 미리보기 + CP·속성 요약)에서, 파견은 군 단위 (파견 중인 군은 재파견·편성 변경 잠금)
- 배타 규칙: 몬스터는 **종 카드 수 기준** — 카드 2장이면 두 군에 동시 편성·파견 가능, 같은 군 내 같은 종 중복 불가.
  유물은 uid 개체 단위로 한 군에만 연결 (같은 종류 여러 개면 각 군에 하나씩)

### 5.1-1 원정 지도와 회군 (2026-08-27)

- **원정 지도**: 전용 시트 — 진입은 홈 타이틀 우측 지도 아이콘(에셋). 홈 '원정 현황'은
  원정별 한 줄 요약을 **곧 돌아오는 순**으로 쌓고(정산 대기가 맨 위), 줄을 탭하면 아코디언으로
  가속·갈림길·회군 액션이 펼쳐진다 (한 번에 한 줄, 정산 📜는 줄에 인라인).
  캠프(아래)→권역 1~4(위) 세로 등반 구도에 파견 마커가 실제 경로를 따라 움직인다.
  여정은 **이동(앞 22%) → 탐사(현지 선회) → 귀환(뒤 22%)** 3막.
  잠긴 권역은 안개+🔒 — 지도가 곧 진행 티저 (도감 ?와 같은 원리). 소요 시간은 티어 고정 그대로이며
  지도는 시간을 거리감으로 번역해 보여줄 뿐 밸런스에 관여하지 않는다.
- **회군**: 진행·보상을 포기하고 원정을 중단한다. 순간이동이 아니라 **현 위치에서 캠프까지 걸어서 복귀** —
  복귀 소요 = min(경과 시간, 편도 이동 시간 22%). 복귀가 끝나야 군이 풀린다 (마커는 길을 되짚어 온다).
  - 오발송 취소(주 용도)는 파견 직후라 사실상 즉시 복귀 — 비용이 "얼마나 멀리 갔나"에 비례해 저절로 공정
  - **귀환 단계(뒤 22%)에는 회군 불가** — 도착 시간은 같은데 보상만 사라지는 순손실이라 막는다
  - 적재 미끼는 회군 확정 시 즉시 환급 (취소가 제작 재화까지 깎으면 벌이 된다) · 일지·통계 흔적 없음
  - 회군 중 가속·갈림길 불가 (귀로 가속 허용 여부는 추후 별도 결정) · 튜토리얼 첫 정찰(30초)은 회군 버튼 없음

### 5.2 조우 시퀀스 생성 (결정론)

파견 확정 시 `seed`가 정해지고, 시드에서 조우 시퀀스가 유도된다:

```
각 슬롯 roll → 몬스터 조우 72% / 보물 12% / 함정 10% / 채집 6%
몬스터 조우: 지역 출현 테이블(가중치)에서 종 선정 → 난이도 E 산출
```

### 5.3 조우 판정 모델

파티 유효 전투력:

```
P = Σ_unit ( CP × elemMult(unit.elem, region.elem) ) × synergyMult(party)
```

- **P ≥ E (승리)**: 파티 현재 HP에서 `E/P × k` 비례 피해. 포획 판정 진입(§7)
- **P < E (패주)**: 대미지 크게, 해당 조우 보상 없음. HP 0 → **전멸: 조기 귀환**, 그때까지 획득의 50%만 반입
- HP는 원정 내내 지속 감소(정령 시너지·야영 이벤트로 회복) → "얼마나 깊이 버티나"가 파티 질의 척도

### 5.4 갈림길 이벤트 (푸시 상호작용)

원정 중 정해진 시점에 발생, **푸시로 통지**:

> "원정대가 수상한 제단을 발견했습니다. 조사할까요?"

- 선택지 2개: 안전(소보상 확정) / 위험(P 검사 → 대성공 희귀 보상 or HP 대미지)
- **4시간 미응답 시 자동으로 안전 선택** (플레이어 손해 없음, 응답하면 리스크·리턴 선택권)
- v1은 갈림길 결과를 일지에서 소급 확인 + 귀환 전 앱 접속 시 선택 가능. **푸시 탭→즉답은 v1.5** (M6)

### 6.1 해금 조건 사다리 (2026-08-25 원칙 · 2026-08-26 11관문 재설계)

해금은 **도감 종 수 AND 재료 개수** 두 조건이다. 둘의 역할을 갈라 둔다:

- **도감 = 제동.** "이 지역을 얼마나 탐험했는가". 진행 속도를 정하는 건 이쪽이다
- **재료 = 값.** 문을 여는 데 치르는 비용. **권역 진입 관문에만** 앞 권역 재료 2종 대칭으로 건다
  (권역 내 관문은 도감 단독 — 게이트 두 축을 겹치면 곱으로 작용한다)

관문 깊이는 앞 소지역 포획 가능 16종 대비 비율로 읽는다: 초반 38~56%(맛보기), 권역 진입
56→88→100% 단조 증가, 후반은 전부 16종 완채(= 영웅 3종까지). **후반 관문의 실체는 영웅
꼬리다** — 포획률 6%짜리 영웅을 다 잡아야 다음이 열리므로, 영웅 스폰 가중치(§6)와 한 쌍의
다이얼이다. 계측 교훈: 심연 완채 관문 + 영웅 가중치 1은 19일짜리 데드존을 만든다(D17→D36).
가중치 2로 완채 관문이 6~8일, 가중치 1은 최후반(협곡→심장부) 전용.

**왜 재료를 제동으로 쓰지 않는가** — 재료는 원정 횟수에 비례해 쌓이므로 **역진적**이다.
계측상 재료를 3배 올려도 "보통" 유저는 하루 밀리는데 "방치" 유저는 사흘이 밀린다.
빠른 유저는 그대로 통과시키고 느린 유저만 때리는 게이트다. 반대로 도감 조건은
쿠폰 수집가 문제(이미 잡은 종은 카드만 준다) 때문에 **모두에게 체감 난도가 붙는다**.

측정: `npx tsx scripts/unlock-sweep.ts --days 70` (11관문 일차 판정, `--search` 단계 탐욕) ·
`npx tsx scripts/simulate.ts --days 21 --gates` (병목이 도감인지 재료인지).
불변식은 `tests/content.test.ts`의 «지역 해금 조건» 블록이 고정한다 — 바로 앞 지역만 참조 /
전설 없이 달성 가능 / 권역 진입 비율 단조 증가 / 재료는 진입 관문 한정·도감의 1.5배 이하.

## 7. 포획 시스템

### 7.1 판정

승리한 몬스터 조우마다 1회:

```
포획률 = 기본률(등급) × 미끼 배수 × 마일스톤 보정
기본률: 일반 45% / 고급 34% / 희귀 18% / 영웅 6% / 전설 1.5%
```

- **미끼**: 지역 재료로 제작하는 소모품. 파견당 최대 3개 적재, 효과 포획률 ×2. 안 쓴 미끼는 귀환 시 반환된다
  - 자동 사용 정책 (2026-08-25 개정): **아직 도감에 없는 희귀 이상** 조우에만 쓴다.
    이전에는 보유 여부를 보지 않아 늪 도감 39~41종 구간(= 화산 해금 게이트가 걸리는 구간)에서
    소모 미끼의 **약 78%가 이미 잡은 종에 버려졌다**. 이미 잡은 종에 써서 얻는 건 카드 1장뿐인데
    미끼의 값어치는 도감을 늘리는 데 있고, 해금 게이트도 도감이 정한다(§6.1)
- 실패해도 **목격 기록**(도감 실루엣 + 서식지 힌트) → "다음엔 잡는다" 동기
- 광고(IAA) 버프: 포획률 ×2, 30분 (미끼와 중첩 시 ×4 상한)

### 7.2 도감 (수집의 축)

- 도감 화면은 **몬스터 / 유물 / 업적 3탭** (2026-08-23 — 모바일 스크롤 최소화)
- 몬스터 종당 3단계: **목격**(실루엣) → **포획**(정보 공개) → **각성**(★3 도달, 도감 일러스트 테두리)
- 유물 도감(v7): 등급별 그리드, **획득 이력** 기반 — 종이 사라진 과거 세이브(분해 제거 전)도 흐린 아이콘으로 남는다
- 업적 보상(골드·가루 + 일부 영구 버프): **소지역당 6계단** (2/5/9/12/16/18종 — 2026-08-26 12지역
  개편, 12지역 × 6 = 72개. 티어별 골드·가루·버프 총량은 구 13계단 사다리에서 보존, 버프는
  권역당 4개를 진입 9/18·2소 12·3소 16계단에 재배치) + 공통 17종 (종족 5·8종, 총 10~216종 사다리,
  초월 1·3종) = 총 89개
  - 예: "물안개 해안 완전 정복 — 전 파티 HP +3%" (버프는 전부 콘텐츠 데이터)
- **사다리는 두 축이다** (2026-08-25 사용자 결정 — 초월 3종 추가로 상한이 어긋난 걸 고치며)
  - **서식종 축** (소지역 18 · 종족 · 총합 216): 출현 테이블에 실제로 등장하는 216종만 센다.
    초월은 habitat이 심장부여도 **집계에서 뺀다** — 넣으면 심장부 서식종 15종 + 초월 3종으로
    "분화구 심장부 완전 정복"이 터지고, 219종 중 216종에서 "신대륙 도감의 완성"이 터진다
  - **초월 축** (초월 1종 · 3종): 합성 전용 3종을 세는 별도 계단. 전설→초월 3%에 3종 랜덤이라
    완주 기댓값이 화산 권역 전설 스페어 약 189장(영웅 카드 환산 약 20,000장 — 영웅→전설 4% 기준, 2026-08-26)이다 —
    도감 완주와 자릿수가 달라서, 완성 조건에 섞지 않고 **엔드콘텐츠 축으로 분리**했다
  - 초월 계단 보상은 골드·가루만 준다. 초월 몬스터 자체가 이미 강한 고유 능력(공/체 +20%,
    시너지 증폭 +30%, 보상 +20%)을 들고 오므로 그 위에 영구 버프를 또 얹지 않는다
  - 도감 화면의 몬스터 탭은 그대로 **219종 기준**으로 보여준다 (잡은 걸 안 보여줄 이유는 없다).
    사다리의 모수만 축별로 갈린다
  - 두 축의 꼭대기가 각자 모수와 정확히 같은지는 `tests/content.test.ts`가 고정한다 —
    종을 늘리면서 사다리를 안 늘리면 빨개진다
- 도감 점수 = 목격 1 / 포획 3 / 각성 5점 합산 → (v2) 랭킹 지표

## 8. 유물 시스템 (전리품 파밍)

원정의 전리품 축. "신대륙 유적에서 유물을 발굴해 원정대를 무장시킨다."
설계 목표: **아이템의 다양성과 고유 능력이 게임의 변수를 만든다.** 능력은 코드가 아니라
훅 기반 데이터로 정의해(스키마: DATA §1.5) 콘텐츠 추가만으로 계속 확장한다.

### 8.1 착용 구조 — 팀 단위 4슬롯

| 슬롯 | 정체성 | 주옵션 경향 |
|---|---|---|
| 무기 | 공격 | 파티 ATK% |
| 방어구 | 생존 | 파티 HP%·피해 경감 |
| 깃발 | 시너지·광역 | 시너지 증폭, 파티 광역 효과 |
| 부적 | 유틸 | 포획·탐사·보상 |

- **몬스터 개체별이 아니라 팀 프리셋에 장착.** 216마리 × 슬롯의 인벤토리 관리 지옥을 피하고,
  장비 선택이 편성 퍼즐(필러 2)의 한 층으로 통합된다
- 동시 파견 팀이 늘수록(1→4군) 필요한 세트가 늘어 파밍 수요가 자연 확장 — **같은 종을 2개 모으면
  두 군에 동시 장착 가능** (종 단위 개수 배타, 몬스터 카드와 동일 — 2026-08-23)
- 파견 배타도 개수 기반: 사용 중 수 + 1 > 보유 수면 파견 불가. 강화는 파견 중에도 허용
  (강화가 종에 붙어 개체 잠금이 무의미 — 몬스터 레벨업과 동일 규칙)

### 8.2 등급과 옵션 — 파밍 동기의 핵

**유물은 몬스터처럼 종 단위다 (2026-08-23 v6 개편 — 부옵션 폐지).** 같은 유물을 중복 획득하면
개수가 쌓이고, 강화는 종당 하나로 공유한다. 개체 굴리기(부옵션 롤) 대신 **개수 수집**이 파밍 동기:
여분은 합성 재료가 되고, 2개 이상 모으면 여러 군에 동시 장착할 수 있다.

| 등급 | 주옵션 | 고유 능력 |
|---|---|---|
| 일반 | 1 | — |
| 고급 | 1 | — *(2026-08-23 5등급 개편 — 몬스터와 등급 체계 통일)* |
| 희귀 | 1 | — |
| 영웅 | 1 | **조건부 옵션 1** (예: "화산에서 ATK +20%") |
| 전설 | 1 | **빌드 정의급 고유 능력** |

- 영웅급의 조건부 옵션(지역·속성·파견 단계 조건)이 지역 특화 세팅을 만든다 —
  "화산용 세트, 심층용 세트"처럼 상황별 최적이 갈리는 것이 다양성의 실체

### 8.3 고유 능력 — 훅 9종 기반 확장 설계

능력은 "원정 파이프라인의 훅에 꽂히는 데이터"다:

| 훅 | 시점 | 능력 예 |
|---|---|---|
| expeditionSetup | 파견 구성 | 시간 -25%, 조우 +2, 희귀 출현 가중 |
| computeParty | 유효 CP 계산 | 스탯·속성별·종족별 배수, 시너지 증폭 |
| beforeEncounter | 조우 직전 | 첫 조우 자동 승리, 함정 회피 |
| afterVictory | 승리 후 | HP 회복, 추가 골드 |
| afterDefeat | 패배·전멸 시 | 피해 경감, 1회 부활, 반입 비율 증가 |
| captureRoll | 포획 판정 | 포획률 가산, 실패 시 재시도 |
| crossroad | 갈림길 | 실패해도 절반 보상, 위험 성공률 증가 |
| lootRoll | 드랍 판정 | 골드·재료·유물 드랍률 |

#### 9.1-1 목표 곡선의 기준선 문제 (2026-08-25 계측)

**§9.1의 목표 곡선은 "상점을 한 번도 안 쓰는 봇"으로 잡혔다.** simulate.ts의 봇은 골드 상점을
이용하지 않고, 미끼를 3개만 들고(파견당 적재 상한이 3이라 **2군부터는 맨몸으로 나간다**),
모래시계를 사지도 쓰지도 않으며, 월간 출석도 하지 않는다. 실유저는 이 중 아무것도 안 할 이유가 없다.

같은 "보통"(하루 4회) 유저를 행동만 바꿔 재보면 (`scripts/spend-sim.ts --ablation`):

| 행동 | 숲 | 늪 | 화산 |
|---|---|---|---|
| ① 기본 봇 (= §9.1 목표 곡선의 기준) | D1 | D6 | D9 |
| ② + 미끼를 팀 수만큼 확보 | D1 | D6 | D10 |
| ③ + 골드 상점 일일 한도까지 | D2 | D7 | D10 |
| ④ + 보유 모래시계 사용 | D2 | D6 | D8 |
| ⑤ + 재료를 모래시계로 세공 | D2 | D5 | D8 |
| ⑥ + 월간 출석 (= **무과금 최선**) | D2 | D5 | D7 |

*(슬롯 게이트까지 합친 2026-08-25 통합 상태 기준)*

즉 **무과금이라도 제대로 놀면 화산이 D7**이고, 목표창(D10~14)보다 3일 빠르다.

**가장 크게 뒤집히는 건 방치다.** 기본 봇으로는 늪 D17·화산 D25인데, 상점 모래시계를 챙기면
**늪 D9·화산 D13**이 된다 — 약한 파티를 상점 시간으로 벌충하기 때문이다.
슬롯 게이트가 방치에 준 타격은 "게임을 아는 유저"에겐 절반쯤 상쇄된다.

두 가지 함정이 계측 중에 드러났다:

- **제작이 해금 재료를 잠식한다** — 모래시계 세공도 미끼 꾸러미도 다음 지역 해금과 **같은 재료 풀**을 먹는다.

  막지는 않는다 — 지금 시간을 벌지 나중에 문을 열지는 유저가 고를 문제다
- **미끼가 이미 포획한 종에도 쓰였다** (`expedition.ts`가 `alreadyCaptured`를 계산해 놓고
  `shouldUseLure`에 넘기지 않았다). 늪 도감 39~41종 구간에서 소모 미끼의 약 78%가 낭비됐다.

**결론**: 목표 곡선을 다시 잡을 때는 ①이 아니라 ⑥을 기준선으로 삼아야 한다.

#### 9.1-2 과금 구간별 진행 속도 (2026-08-25 계측)

> **단가 개편 (2026-08-29)**: 실결제 단가를 **1💎 = 10원**(₩10,000 = 1,000💎)으로 확정하면서

> 아래 본문의 "1💎 = 50원"과 💎 수치는 개편 전 기준 서술이다.
> IAP 팩 6종 (2026-08-29 확장): `diamonds_300`(₩3,000, 10원/💎) · `diamonds_550`(₩5,000, 9.1원) ·

**전제**: IAP는 아직 없다(§9.1 다이아 항 · M6 예정). **광고(IAA)도 코드에 없다** —
`balance.ads.daily`와 `adBuffMult:2`, zod 선언은 있지만 런타임 참조가 0이고
`capture.ts`의 `buffMult`에는 프로덕션에서 리터럴 1만 들어간다. 즉 §9.2는 아직 설계 문서일 뿐이다.
따라서 아래는 **충전이 붙었다고 가정한** 추정이다.

다이아 단가는 **뽑기 1회당 원화**로 역산했다. 재화 1개당 단가는 게임마다 8배씩 흩어지지만

이 게임의 몬스터 뽑기가 30💎이므로 **1💎 = 50원**이면 1,500원 — 대역 하단이고 방치형이니 하단이 맞다.
*(주의: 이 대역은 최대 패키지 기준이다. 월정액을 끼면 실효 단가가 4~7배 좋아지므로 50원은 보수적 가정이다.)*

지역 해금 일차 — 상점·출석을 챙기는 실유저 모델, 시드 5개 중앙값

> ⚠️ **완성 일차는 점추정으로 읽지 말 것.** 마지막 전설 몇 종이 순전히 운이라 시드 분산이 매우 크다 —
> 같은 설정("보통", 항상 심층)에서 D225와 D288이 함께 나오고, 티어를 섞으면 D160과 미완(214종)이 함께 나온다.
> 위 표는 시드 2개의 중앙값이므로 **"대략 7~10개월" 이상으로 정밀하게 말할 수 없다.**
> 192종(비전설)까지의 D22~D28은 분산이 작아 신뢰할 수 있다 — 꼬리만 요동친다.
> 행동별 기여를 볼 때도 분포가 겹치는지부터 볼 것 (`scripts/codex-ablation.ts`).

두 가지가 눈에 띈다:

- **접속 빈도가 거의 영향을 안 준다** (219~300일, 1.4배). 지역 해금이 4~13일로 3.3배 갈리는 것과 대조적이다.
  총 런 수가 6,048~7,904회로 비슷하게 수렴하기 때문 — 모래시계가 접속 빈도 차이를 메운다.

  필요한 총 획득이 24×H(24) = 90.6장인데, 18종까지 31.8장이고 **남은 6종에 58.8장**이 더 든다.

**2026-08-26 12지역 개편 재계측** — 개편 직후 완성이 **D105~185로 붕괴**했다. 원인은 12분할의
기하학: 소지역 전설 풀이 6종→2종이 되며 심층 조우(시드로 풀에서 1종 선택)의 종당 타겟팅이
3배 정밀해졌고, 주 경로인 합성은 그대로였다. 감속 다이얼 둘로 복원 —
심층 legendaryChance 5%→**2%**(구 6종 풀의 종당 조우율 0.83%/런과 등가) ·
영웅→전설 합성 6.25%→**4%**. 해금 곡선은 전설 무관(관문이 전설 없이 달성 가능)이라 안 움직인다.
복원 후 계측(500일·시드 3, "보통" 완성 지향): 192종(비전설 전부) **D25** · 197종(전체 90%) **D36** ·
200종 D51 · 210종 D125 · **216종 완성 D197·D205·D279** — 구 219~300일 수명 대역 복원.
비전설이 해금 러닝타임(~D44)의 절반쯤에 이미 차므로 수집의 체감 꼬리는 여전히 전설 24종이고,
"90%까지 6개월" 같은 목표는 **90% 지점이 아니라 완성 꼬리로 잰다** — 90%는 어떤 튜닝에서도
전설 4~5종째에 걸리는 이른 지점이라, 그걸 6개월로 밀면 완성이 2년 너머로 밀려 수집가가 떠난다.

**전설이 들어오는 세 경로 — 조우가 아니라 합성이 지배적이다:**

| 경로 | 심층 1회당 전설 | 전설 1장당 심층 |
|---|---|---|
| **합성** (영웅 여분 2장 → 4% — 2026-08-26 감속) | **0.0083** | **120회** |
| 조우 (심층 2% × 포획 1.5%×미끼2 — 2026-08-26 감속) | 0.0006 | 1,667회 |
| 상점 | — | 무과금 143일에 1장 |

*(위 표는 6.25%/5% 시절 실측 77회·667회를 감속 배율로 환산한 값 — 재실측 전 추정)*

합성의 연료는 영웅 직접 포획(심층 1회당 0.06장)이 아니라 **하위 등급 캐스케이드**다 —
일반→고급→희귀→영웅으로 밀어올린 양이 직접 포획분의 약 3배다.
일반이 조우의 54%라 카드가 쏟아지고, 각성이 골드만 쓰므로 **중복 카드의 용도가 합성뿐**이라 그렇다.

상점은 무과금 기준 사실상 무의미하다 — 골드 뽑기가 **일일 1회 한도**(골드는 남아도는데 한도가 제약)라
연 1.8장, 다이아 프리미엄은 월 160💎 ÷ 80 = 월 2회뿐이다.

**설계 함의**: 콘텐츠 수명의 대부분이 전설 24종에 몰려 있다. "도감이 엔드 콘텐츠"(§2 필러 3)에는 부합하지만,
완성 마일스톤이 8~10개월짜리라는 뜻이기도 하다. 조정하려면 손댈 곳은 조우 확률이 아니라
**합성 성공률(fusion.chance.heroic)이나 하위 캐스케이드**다 — 지배 경로가 거기다.

### 9.3 랭킹·반복 과업 (2026-08-23)

**랭킹** — 첫 온라인 기능. 카테고리: 원정 / 몬스터 / 유물 / 과업 / 전투력 → 종합 (부자·합성·전설은 제외 결정).
점수는 전부 세이브에서 파생하며(최고 전투력만 기록값), 산식은 `core/score.ts`가 진실:

- 몬스터: 등급점(10/20/40/80/200) × 권역 배수(tier 1~4 — 2026-08-26 12지역부터 order가 아니라 tier) + 레벨당 5%·성급당 50% 가산. 도감·상세에 종별 점수 노출
- 유물: 등급점 + 강화 단계당 20%
- 원정: 완료당 정찰 1 · 원정 6 · 심층 30점, 전멸 귀환은 절반
- 과업: 반복 달성 횟수 × 과업별 점수
- 종합 = 원정 + 몬스터 + 유물 + 과업×2 + 전투력÷10

**반복 과업** — 업적(마일스톤, 1회성·영구 버프)과 별개의 카운터 기반 무한 반복 축 (tasks.json).
원정 5회 / 포획 20회 / 제작 10회 / 합성 5회마다 소모 재화(골드·가루)만 자동 지급 — 버프 중첩 방지.

**서버** — Supabase(rank_scores + rank_board 뷰, RLS로 원본 차단). 쓰기는 submit-score 엣지 함수만:
익명 신원(playerId + secret 해시, 세이브 v3에 저장)과 점수 상한을 검증. 2026-08-29부터 로그인 세션
제출은 user_id도 연결(0005) — 탈퇴 시 DB cascade로 랭킹 행이 지워진다. 기기 이동은 클라우드 세이브가
담당한다 (세이브 내보내기는 같은 날 제거 — 신원 교체 사고 벡터).
로컬 게임 특성상 위조 원천 차단은 불가 — v1 소프트 신뢰, 상금 랭킹 금지 전제.
제출은 원정 정산·닉네임 변경·랭킹 열람 시 자동, 실패는 조용히 무시 (게임은 완전 오프라인 동작).

## 11. UX 화면 구조 (세로 · 하단 탭 4)

```
[홈]     원정 현황 카드(팀별 진행 게이지·남은 시간·갈림길 대기 뱃지) + 귀환 정산 진입
[원정]   지역 선택 → 팀 프리셋(몬스터 편성 + 유물 4칸 · 시너지·유효 CP 실시간 계산) → 길이 선택 → 파견
[도감]   3탭: 몬스터(지역/종족/등급 필터 그리드 — 실루엣=목격, 컬러=포획, 금테=각성) · 유물(등급별) · 업적
[캠프]   보유 몬스터 관리(레벨업·각성), 유물 인벤토리(강화), 미끼 제작, 설정
```

- 편성 화면이 필러 2의 무대: 몬스터·유물을 바꿔 끼울 때마다 유효 CP·시너지 게이지가 실시간 변동 →
  "숫자가 오르내리는 재미"로 조합 실험 유도
- **파티 슬롯 확장 진입은 편성 시트 '몬스터 (n/N)' 옆 + 버튼** (2026-08-30 사용자 — 캠프 몬스터 목록
  아래에 있던 것을 이동). 슬롯은 보유 관리가 아니라 "몇 마리를 데리고 나가나"의 문제라, 칸이 모자란 걸
  체감하는 자리에 확장을 둔다. 조건(도감 종수 + 골드) 미달이어도 팝업은 열고 확인 버튼만 잠가
  무엇이 얼마나 모자란지 보여준다. 홈 '다음 목표' 카드도 이 진입점(원정 탭)으로 보낸다
- 첫 실행 튜토리얼: 강제 파견 1회(정찰 15분 → **첫 회에 한해 30초로 압축**) → 일지 → 첫 포획까지 3분 내

### 11.2 온보딩 투어 (2026-08-30 확정 — 딤 + 스포트라이트 강제 가이드)

신규 유저 첫 접속 시 화면을 딤 패널 4장으로 덮고 **목표 버튼 자리만 뚫어** 그곳만 누를 수 있게
유도한다. "다음" 버튼으로 넘기는 학습이 아니라 **실제 행동이 곧 진행** — 유저가 진짜 파견을 보내고,
진짜 레벨업을 하고, 진짜 출석 보상을 받는다.

**설계 원칙**
- 진행 판정은 저장 상태·화면 상태의 **술어(predicate)** 로 파생 — "첫 미완료 단계"가 현재 단계.
  별도 스텝 카운터를 저장하지 않으므로 앱 재시작·중간 이탈에도 자연 복구된다 (시트를 닫아버리면
  이전 단계가 다시 안내하는 식). 일회성 사실(지도 봤음 등)만 `profile.flags.tour*`에 남긴다
- 대상 버튼은 `data-tour` 마킹으로 찾는다. 다른 오버레이(일지 연출·시트)가 열려 있고 대상이
  그 안에 없으면 투어는 **숨고 막지 않는다** — 연출·시트 조작은 자유
- **건너뛰기 상시 제공** (확인 다이얼로그) — 스킵하면 기존 튜토리얼 배너가 안전망으로 복귀
- 기존 장치(첫 정찰 30초 압축·첫 포획 100% 보정·tutorialDone=첫 정산)는 그대로 두고 투어가 감싼다

**단계 (13스텝 — 원정 → 지도 → 캠프 → 도감 → 일지 → 출석):**

| # | 안내 | 완료 술어 |
|---|---|---|
| 0 | 환영 카드 [시작하기] | flags.tourIntro |
| 1 | 홈 "원정 보내기" 버튼 | 원정 탭 진입 or 파견 이력 |
| 2 | 출발 버튼 (첫 정찰 30초) | 파견 이력 존재 (성공 시 자동 홈 복귀) |
| 3 | 홈 탭 (이탈 시 복귀 유도) | 홈 탭 or flags.tourMap |
| 4 | 🗺️ 지도 열어보기 | flags.tourMap (지도 오버레이 열림 시 기록) |
| 5 | 캠프 탭 | 캠프 탭 or 레벨업 이력 |
| 6 | 몬스터 카드 탭 | 몬스터 시트 열림 or 레벨업 이력 |
| 7 | 레벨업 버튼 (시트 안) | 로스터에 Lv.2+ 존재 |
| 8 | 도감 탭 | 도감 탭 or flags.tourCodex |
| 9 | 도감 안내 카드 [다음] | flags.tourCodex |
| 10 | 홈 탭 복귀 | 홈 탭 or 첫 정산 이력 |
| 11 | 📜 일지 열기 (귀환 전엔 대기 카드) | journalArchive 1건+ (= tutorialDone) |
| 12 | 📅 출석 보상 받기 | 이번 달 출석 1일+ |
| 13 | 완료 카드 [모험 시작!] | flags.tourDone |

### 11.1 사운드 — v1은 효과음 전용 (2026-08-23 확정)

- **BGM·지역 앰비언스는 v1 보류** (소스 미확보 — 추후 CC0 음원 별도 검토). 효과음만으로 시작한다
- 소스: **Kenney CC0 3팩** (interface-sounds / impact-sounds / digital-audio) — 파일 매핑 대장은 ASSETS §5

  축하·마법 이벤트는 digital-audio의 차임 계열(포획·레벨업·각성·마일스톤).
  **SF 계열(laser·zap·spaceTrash)은 세계관 충돌로 사용 금지**
- 재생 원칙: 액션·일지 카드당 1음 (레이어링 없음). 일지 타임라인은 카드 공개 시점에 이벤트별 1음 —
  포획 결과음이 승리음보다 우선 (감정 포인트가 포획이므로)
- 설정: `settings.sound` 토글 (캠프 설정, 기본 켬). 모바일 자동재생 정책 대응 — 첫 사용자 제스처에서
  AudioContext 활성화. 로드·재생 실패는 조용히 무시 (사운드는 항상 non-critical, 게임 진행을 막지 않는다)
