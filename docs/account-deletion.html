1. 앱에서 직접 삭제 (즉시 처리)

  1. 게임 실행 후 하단의 ⚙️ 설정 탭을 엽니다.
  2. 계정 섹션에서 [탈퇴] 버튼을 누릅니다.
  3. 안내에 따라 확인 문구를 입력하면 계정이 즉시 영구 삭제됩니다.

2. 이메일로 삭제 요청 (앱을 삭제한 경우 등)

앱에 접근할 수 없는 경우, 가입에 사용한 구글 계정 이메일로 tngus842655@gmail.com 으로 "계정 삭제 요청"을 보내주세요. 본인 확인 후 지체 없이(영업일 기준 7일 이내) 삭제 처리하고 회신드립니다.

3. 삭제되는 데이터

계정 삭제 시 다음 데이터가 모두 영구 삭제됩니다.

  • 계정 정보: 구글 계정 이메일, 계정 고유 식별자
  • 게임 데이터: 클라우드 세이브, 이 계정에 연결된 기기 세이브, 닉네임, 프로필
  • 랭킹 데이터: 이 계정의 랭킹 기록

4. 보관되는 데이터

원칙적으로 보관하는 데이터는 없습니다. 다만 관련 법령에 따라 보존 의무가 있는 경우 해당 법령이 정한 기간 동안만 보관 후 파기합니다(예: 유료 결제 도입 시 「전자상거래법」에 따른 거래 기록 5년).
