# 개발 계획

## 확정 사항 (2026-08-17)

- **타깃: 모바일 웹 우선** — 세로 화면 기준 레이아웃, 터치 타깃 44px 이상,
  safe-area 대응. 데스크톱은 560px 중앙 정렬로 수용.
- **메뉴 구성은 원작을 따른다** — 원작 인게임 메뉴는 도시 / 영웅 / 맵 / 길드 / 시장 / 랭킹 / 정보.
  현재 구현: 도시 / 영웅 / 맵 / 정보 (길드·시장·랭킹은 시스템 미구현).
  원작처럼 **건물을 눌러 기능을 연다** — 병영→훈련, 연구소→병종 연구, 주점→영웅 고용.
  ('도감'은 원작에 없던 탭이라 '정보' 안으로 편입)
- 스택: TypeScript + Vite (프론트), Supabase (DB — 호스팅, Docker 없음)
- 순서: 싱글 프로토타입 → 서버 기반 멀티
- 데이터 근거: 본인 기억보다 **수집 자료 우선** (자료집 아티팩트 참고)
- 법적 방침: 시스템은 재현하되 표현물(아트·명칭·텍스트)은 추후 교체 가능 구조. 원작 IP 보유사(남경광휘호동)는 현역이므로 공개 전 자체 에셋 교체 또는 라이선스 문의.

## 건축 트리(건설 선행 조건) 조사 현황 — 2026-08-17

`data/buildings/base.json`의 `requires`("B를 지으려면 A가 Lv.N 이상")는 **전부 estimate**다.
원작 건축 트리 표 자체는 **실존이 확인됐고 위치도 특정했지만 아직 열람하지 못했다**(아래 이그레스 제약).

**확인된 원작 해금 조건 (실측)**

| 조건 | 효과 | 출처 |
| --- | --- | --- |
| 초급병영 **Lv.1 / 5 / 10** | **1계 / 2계 / 3계** 병종 훈련 해금 | 新浪 内政建筑_初级兵营 (2008) |
| 시청(市政中心) **Lv.5** | 다른 건물 **철거** 기능 해금 | 七龙纪II 건물 안내 |
| 주점(酒馆) **Lv.5** | **마구간(马厩)** 건물 해금 → 탈것 구매 | 대만판 七龍紀 공략 |

→ 원작이 "A건물 Lv.N → B 해금" 구조인 것은 **확정**. 다만 병영은 레벨 간격이 넓다(1→5→10).

**그 밖에 확인된 수치·규칙**

- **초급병영 = 1~3계, 고급병영 = 4~6계** — 병영이 2채로 나뉘어 병종 등급을 가른다.
  병영 레벨이 높을수록 훈련 시간이 짧아진다.
- 목재가공소: **레벨당 목재 생산 +5%** (가공 건물이 원자재 생산에 곱해지는 2단 구조)
- 병기고(军械库): 도시 병사 물리방어 증가, **최대 20레벨**
- 시청: 세금 징수 + 城市之心 교환(새 도시 개척용). 인구·문명도가 분성 조건.
- 성(城堡)은 성벽(城墙) 방어값에 가산.
- 七龙纪II 건물 전체 목록: 자원(伐木场·木材加工厂·石头矿·石材厂·水晶矿·水晶提炼厂·农场·磨房·面包房),
  군사(军事指挥所·初级兵营·高级兵营·工场·竞技场·城墙·箭塔·城堡·医疗帐篷·生命之井·军械库·
  英雄训练场·藏兵洞·传送门·大兵营·兽栏·马厩)

> ⚠️ 현재 구현(`startTraining`의 `tier <= 병영레벨`)은 원작(1/5/10)과 다르다.
> 원작을 따르려면 병영 최대 레벨을 20까지 늘리거나 초급/고급 병영 2채로 나눠야 해서
> 밸런스 재설계가 필요하다 — 착수 전 결정할 것.
